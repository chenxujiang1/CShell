# 多行命令边界与轻量内容比较

日期：2026-10-27。在 ADR-0128 基础上继续打磨，不增加长期体验验证。

## 命令记录

初始化脚本保留原 PS2，在续行提示符前后发出 OSC 133 P;k=s / B；解析器将各输入段合并，去除续行提示符。最多 64 个续行段，沿用 4 KiB 命令、128 条 / 128 KiB 元数据上限。支持带参数的 A 和 D 标记；缺失历史或截断设置 command_complete=false，禁止把片段直接作为完整命令复制。

这仍是 shell 报告的屏幕语义，非原始按键审计，不读取 history 文件；复杂提示符重绘和不可见空白不能宣称还原原始输入字节。Bash 4.4+ 当前 shell 和可选 zsh 初始化不修改启动文件。

续行初始化使用独立标记，已启用旧集成的 shell 重新执行脚本即可补齐 PS2，不重复包装 PS1 或追加原钩子。

## 有预算的内容比较

目录比较默认开启轻量核对，也可关闭。只检查两侧大小相同、元数据不同的普通文件；每文件最多 1 MiB，每侧合计最多 8 MiB / 32 个文件，单文件两秒、整个核对最多十秒。采用原防链接本地读取与 SFTP 只读摘要，不通过 SSH exec 推断 SFTP 命名空间，不为比较读取大文件。超时、读取失败或超预算时仍为“元数据差异”，不能降级为内容一致。

分别标记“内容一致”“内容不同”“元数据一致”和尚未核对的“元数据差异”。内容一致不能选择覆盖，可开启显示一致项查看；元数据一致不代表做过摘要验证。缺失修改时间的小文件也可在预算内核对，避免同内容因时间戳不保留而重复传输。

记录原始元数据的规范摘要，提交前重新枚举对照，不重复执行全部内容读取。对已确认为内容不同且用户选中替换的文件，把原两侧摘要绑定到既有传输草稿；上传 / 下载时按方向对应源目标。后续内容不符合预览时沿用原安全队列拒绝机制。

## 状态与重试

收起窗口后，在传输区显示比较就绪、已提交或失败摘要。仅客户端明确未发送的同步请求允许直接重试，保留原选择；后台已认领、结果不明确或过期时，仍查询原任务或重新比较。新增请求出站标记，防止其他操作的拒绝误清同步提交状态。
