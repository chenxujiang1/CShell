# SSH 多轮键盘交互认证

后续的合并配置页、可排序认证与连接时保存凭据见 [0112](0112-ordered-interactive-ssh-login.md)。本文记录最初的键盘交互实现。

在保存的 SSH 配置“账号与认证 → 密码”中增加“键盘交互验证（验证码 / 密码）”。默认关闭以保留原有密码认证行为；配置存入既有 options JSON，IPC 新增 bool 字段，旧配置默认 false。密码继续使用原有系统凭据或 Vault 存储，不复制到配置数据库。

连接使用已有的 russh keyboard-interactive responder。在验证主机密钥后，服务器逐轮请求验证码等内容，桌面弹框显示明确的账号及主机。未保存密码时所有提示手动填写；服务器明确要求单个、无回显的普通密码时使用已有密码，每次连接最多自动使用一次。OTP、one-time password、passcode、PIN、新密码及未知提示不匹配自动填充。混合提示只向桌面发送需要手动填写的项，后台合并顺序。支持验证码验证后 SSH partial_success 要求切换到 password 方法；验证未通过时不尝试密码。

临时挑战通过现有已认证 Vault IPC 通道轮询及一次性回复，协议 minor 61。挑战 ID 是随机 UUID，最多 32 个待处理挑战，每轮最多 120 秒，取消、Vault 锁定和任务取消均移除挑战，旧回复和重复回复拒绝。挑战与应答不写磁盘或终端日志，Debug 脱敏，应答和暂存密码在退出作用域时清零。已保存密码不发送到桌面。取消不会自动重试认证。

桌面独立 worker 避免等待 SSH/SFTP 创建时阻塞验证码交互；主窗口和独立 SFTP 窗口均可响应验证。焦点按原生窗口及挑战 ID 维护，验证期间屏蔽终端输入并解除同步输入。SFTP 与跳板的交互认证连接等待延长到 300 秒，SFTP 客户端创建等待 330 秒，普通文件操作仍使用原超时。退出 GUI 可取消本地会话创建等待。

验证包含真实本机 SSH 服务器的两轮提示和 partial_success/password 切换、错误验证码不触发密码、后台 OTP 后自动密码、多提示合并、密码仅自动使用一次、取消及过期回复、Vault 世代失效、弹框连续字符输入与 Enter/Escape、IPC 脱敏以及 SQLite/IPC/配置控件持久化。

关闭正在验证的 SFTP 标签按连接 UUID 取消对应挑战，并为迟到挑战保留有界取消记录；不会取消其他主机或同一配置的 SSH 验证。人工验证输入超时单独分类，避免自动网络重试重复弹出验证码。密码编辑控件的 Enter/Escape 焦点写入延迟到 input 读取锁释放后，避免锁重入卡住。
