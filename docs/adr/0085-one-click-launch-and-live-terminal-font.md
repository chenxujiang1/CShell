# ADR-0085：一次点击连接与即时字号调整

- 日期：2026-10-15

新标签的 Idle 初始化握手尚未结束时，用户连接动作已进入 watch 通道。
旧初始化会清除 session_opening，使工作区提前清除 pending_launch；连接
即使随后成功，也无法绑定原空标签。现在在同一状态锁内先接收排队动作，
不执行空闲清理；提交连接被拒绝时明确解除等待并显示提示。

终端默认字号从 20 px 增至 24 px。状态栏提供 12～40 px 数值控件，拖动或
输入后立即重建字形图集、失效几何缓存、重算行列数和日志换行。修改不创建
新会话；窗口恢复后沿用字号，多窗口同步。扩展静态 ASCII 字形格，避免大
字号被截断；Unicode 排版与 ASCII 使用相同字号。字号保存在数据目录的
display-settings.json，不进入 Profile/凭据数据库；下次启动读取。

SSH 用户名从常规页移至“账号与认证”页，与密码、认证方式及密钥设置同页，
保持原有凭据保存、清零及目标绑定流程。

验证：延迟初始和第二次握手，只点击一次连接，检查仅一次创建且绑定原标签；
账号和密码同页可编辑；12/24/32/40 px 的 ASCII 与 Unicode 排版；既有完整
桌面、工作台、渲染回归。原生窗口自检在连续呈现中切换四次字号，并验证
窗口缩放和设备恢复。构建与试用产物仍只使用原目录，不停止用户后台。
