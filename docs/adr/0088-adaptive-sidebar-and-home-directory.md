# ADR-0088：自适应侧栏与本地终端主目录

- 日期：2026-10-15

侧栏按会话名称、主机地址、分组层级与当前会话标题的实际字体宽度计算
默认宽度，自动模式最多占窗口的 40%，保留终端空间。边缘拖动转为手动
宽度；标题栏“自动适应侧栏宽度”按钮重新启用自动模式。收起按钮保留
36 px 的窄栏和明确的展开按钮；展开后沿用手动宽度或重新计算自动宽度。
查看菜单里的显示开关继续与同一状态同步。

平台默认本地终端与新发现的 Shell 使用 Home 工作目录策略。Windows
解析 USERPROFILE，Unix 解析 HOME，检查绝对路径和目录存在性；缺失时
明确失败，不再静默继承程序目录。新建本地配置默认选择用户目录，保存
过的 Inherit 与 Explicit 配置仍按原值执行。试用启动器不再预建隐藏的
本地会话，只有明确打开本地终端才创建进程。

验证实际指针拖动、自动宽度恢复、一键收起/展开与布局空间；真实 PTY
读取并比较工作目录与当前用户主目录，持续解析 PTY 输出并回复终端查询，
避免 ConPTY 等待光标位置应答。运行桌面/UI/本地 PTY 回归与后台会话测试。

更新仍复用 target 和唯一试用 bin。后台运行中不覆盖、不强制终止；目录
修复须待后台正常退出并更新后，对新建的默认本地终端生效。
