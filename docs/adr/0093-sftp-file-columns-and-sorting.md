# ADR-0093：SFTP 文件列与双向排序

- 日期：2026-10-16

本地文件表格显示名称、大小、类型、修改时间，默认修改时间降序；不把文件夹
强行放在最新文件前面。远端额外显示属性和所有者，默认文件夹优先、组内名称
升序。远端“文件夹优先”可关闭，使所有条目统一按所选列排序。点击任意表头
选择该列升序，再次点击反转；活动列显示方向箭头。两侧状态互相独立，目录
刷新和导航保留排序，重新绑定会话恢复默认。排序覆盖当前已加载的目录页。

大小、修改时间、权限和 UID 使用原始数字比较，缺失值在升降序下都排在末尾；
相同键以名称和路径稳定决定顺序，避免刷新时跳动。目录大小显示破折号。
类型显示文件夹、符号链接或扩展名文件类型。修改时间按本机系统时区显示到秒。
属性显示 Unix rwx 及 setuid/setgid/sticky 标记，悬停查看八进制权限。

SFTP v3 提供 UID/GID，所有者列直接显示 UID，悬停同时查看 GID；不凭空推断
用户名，也不为了目录展示额外执行远程 shell 命令。IPC 为目录条目增加可选
permissions/uid/gid 字段，原始列表和游标浏览两条路径都透传已有 SFTP 元数据。
旧响应未带字段时显示破折号，新增字段不改变原有字段编号或传输操作。

表头与数据位于同一个水平滚动区域，垂直滚动保持表头可见。窄窗口通过水平
滚动访问所有列；可访问节点同步裁剪到可见区域，完全隐藏的列不暴露可点击
的屏外范围。保留文件拖放、整行信息点击选择、文件夹双击以及固定置顶的
“.”和“..”。底部传输队列与文件表格分开布局，滚动不遮挡暂停和取消。

验证覆盖本地默认时间序、远端文件夹优先、六列升降序、数字比较及缺失值、
权限特殊位、本机时间格式、表头指针交互、两侧排序隔离、导航行固定、
窄窗口边界、拖放不重复提交，以及本地真实 SSH 列表和游标响应中的元数据。
构建复用默认 target，试用程序仅维护原有 bin 中的一套。
