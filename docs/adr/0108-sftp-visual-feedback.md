# SFTP 主机身份、方向与拖放反馈

文件页顶部改为当前主机栏，左对齐显示账号、主机及端口，使用独立的服务器线形图标和较大字号。地址来自当前会话的认证 PeerGet 回复；打开文件管理器时主动读取，无需访问高级页面。显示内容随会话绑定更新，身份尚未返回时不沿用其他会话地址，也不把缓存身份当作实时在线证明。IPv6 地址带方括号。

上传统一为本地 → 远端的暖色箭头，下载统一为远端 → 本地的蓝色箭头。文件栏主操作、目标栏底部提示、任务方向小色标和拖放反馈使用相同语义，文字与箭头同时保留。任务文件名保持普通文字颜色，降低历史任务的视觉噪声。传输按钮只在所选项为 1–128 个普通文件且两侧目录均载入时启用；外部拖入文件沿用原有直接上传行为。

拖动悬停目标栏时展示整栏着色、明显边框、动作与数量提示以及当前目标目录。内部拖动同侧、跨会话、目标目录未载入或数量超限时显示拒绝提示，不加入待传列表。覆盖于文件栏之上的弹框或菜单不作为投放目标。原生外部文件悬停也遵循本地上传到远端的方向；文件实际类型、路径及后台操作继续由原有传输边界验证。

SFTP 工具栏统一采用与主工作台同源的线形图标，后退、前进、上级、刷新、路径编辑与队列暂停/继续使用统一按钮。高频上传、下载保留文字和方向色，其余导航使用紧凑图标及完整悬停/可访问名称。详情、远程编辑、历史/迁移和刷新任务收进“更多功能”；高级页面提供快捷返回文件。默认目录设置移到本地“操作”菜单中，保留原有编辑和保存行为。右侧菜单向左对齐，并约束实际宽度，避免小窗口菜单条目越界。

验证覆盖主机身份与会话切换、IPv6、小窗口菜单切换与返回、内部拖放提示与实际接收、未载入/同侧/跨会话/超量目标、外部文件悬停、原有默认目录子菜单与快捷键、列宽分栏及任务表。身份集成用例通过本地认证 IPC 验证打开时 QueueGet → PeerGet → 两侧 BrowseManaged 的实际顺序。GUI 与共享 UI 组件完整回归，并使用生产控件渲染普通和拖放状态预览。
