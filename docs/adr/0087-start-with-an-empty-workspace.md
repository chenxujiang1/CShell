# ADR-0087：启动时打开空工作区

- 日期：2026-10-15

默认不恢复上次的连接标签。旧逻辑恢复布局与 Profile 引用，却刻意不恢复
运行会话，产生必须再次点击连接的空标签。对于需要重新认证和选择目标的
SSH 工具，启动显示空工作区更清楚，也避免自动创建本地进程或连接服务器。

工作区存储仍先读取并保留 revision，维持自动保存的 CAS 边界；启动使用
单窗口空布局和 Idle 元数据连接，无论是否存在保存布局都不创建或附加终端。
初始化只刷新界面模型，不提交空布局覆盖保存记录。用户编辑新工作区后再
按现有自动保存流程提交。存储读取失败时仍禁止保存，保留错误与恢复入口。

保存的连接配置、凭据及后台进程不变。“已打开的会话”仅列出本次 GUI
运行中打开的会话，运行期范围由多个窗口共享，不落盘；重启不显示上一轮
残留会话。终端轮询和工作区同步共用该过滤，防止任一路径重新填入旧会话。
用户主动使用布局恢复功能仍沿用既有预览确认流程。
会话管理器删除固定的“本地终端”入口；菜单、工具栏及新标签入口保留。

验证覆盖带旧标签/多窗口布局、首次无布局与存储失败；以真实本地 IPC
检查保存布局存在与不存在时均只请求会话列表，即使环境传入旧会话 ID 也
不会附加，也不会把后台旧会话显示到列表。验证本次会话在多窗口共享、
重启后范围清空和关闭后移除。继续验证一次点击连接与完整桌面、UI 回归。
