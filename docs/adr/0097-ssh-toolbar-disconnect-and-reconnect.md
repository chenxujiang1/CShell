# 0097 — SSH 工具栏断开与重新连接

用户需要直接控制当前 SSH 连接，而原来的工具栏只有连接和关闭标签。关闭会删除标签；已有“重新连接（新 Shell）”入口仅适用于已断开的客户端，无法对运行中的 SSH 会话执行完整重连。

工具栏新增“断开”和“重新连接”。目标固定为当前终端标签绑定的 SSH 配置，与侧栏当前选中的其他主机无关。本地终端和空工作区禁用 SSH 控制。小窗口保留两项主操作，部分辅助操作移入“更多”。

断开通过现有显式 SessionCloseRequest 结束 SSH 会话，收到匹配的关闭响应并确认后台列表不再包含该会话后，删除运行时 session ID，保留标签、配置绑定、终端快照和记录。重新连接先执行同样的确认流程，然后用原 profile ID 创建新会话，并绑定回同一个 tab ID。已断开的标签可以直接提交新连接。

等待关闭期间占用工作区 pending_launch，防止切换/移动标签或其他连接命令覆盖本次操作；按钮与 SFTP 入口随状态禁用。开始操作时清除待粘贴输入并解除同步输入。旧连接是否关闭不确定时，不创建新会话，保留原绑定、显示错误并尝试重新观察旧会话。

客户端在关闭确认后可能立即收到显式重连命令。IPC worker 在与 open_profile_action 相同的锁内检查新命令，避免清除新请求的 opening 状态。显式终止前先查询列表；如果后台重启导致旧 ID 已不存在，确认缺失即可继续，无需发送必然失败的关闭请求。用户操作提交不做隐式重放，不改变原有不确定创建/终止保护。

验证：工作台宽窄窗口点击和禁用测试；真实本地 IPC 的断开后再连、运行中直接重连、重复点击、关闭确认不确定、侧栏选中不同主机、标签与配置保持、快照保留及本地终端禁用测试；完整桌面回归。IPC 测试使用合成服务验证请求顺序，后台和 SSH 协议本身沿用已验证的会话关闭/创建实现，本轮不修改后台。

只更新既有试用 GUI，不新建二进制副本，不修改用户连接配置或凭据。
