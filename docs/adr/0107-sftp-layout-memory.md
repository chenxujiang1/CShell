# SFTP 可调整布局与窗口记忆

文件栏表头各列的边界可拖动，本地四列与远端六列分别保存逻辑像素宽度。首次沿用自适应名称列，拖动后按用户指定宽度恢复；窄列标题及内容省略显示，最后一列的拖动命中区位于可见表头内。拖动通过按下时指针与原始列宽计算绝对位移，不将累计位移反复加到当前值。

中间分隔线调整本地/远端宽度比例，传输区上沿调整传输区高度比例。两种比例与窗口大小独立，缩放窗口时按可用空间换算，保留两侧工具栏和传输操作的最小空间。窄文件栏使用简短工具栏文字，目录和任务列表保持各自滚动。拖动结束后尺寸保持，移动鼠标不继续调整。

布局属于全局偏好，独立于浏览器的会话状态；切换会话时不重置。列宽、分栏比例及传输区比例保存在现有 sftp-settings.json 的 layout 字段，鼠标释放时保存，退出时补存未提交的拖动结果。窗口正常位置、逻辑客户区尺寸和最大化状态保存在 window 字段，移动/缩放停止约 350 ms 后写入，关闭时补存。最小化及零尺寸不会覆盖正常几何，最大化只更新标记，保留还原尺寸。

恢复窗口前枚举当前显示器，支持负坐标屏幕，按目标屏幕 DPI 校正尺寸；原显示器移除或保存位置越界时回到可用屏幕范围。原生 SFTP 窗口保持独立于主窗口。布局设置不会恢复旧连接、旧会话或标签。

设置使用可选字段及默认值兼容旧文件，有限数值校验和尺寸范围约束防止异常布局。所有设置变更在进程内串行读改写，并通过现有临时文件原子替换，布局、窗口、默认本地目录和收藏相互保留。普通无界面 UI 测试不读写操作者布局，持久化与原生窗口验证使用隔离测试目录。

验证包括实际鼠标拖动与松手、列宽不触发表头排序、两侧独立、切换会话保留、小窗口极端比例、旧设置兼容、设置合并往返、多显示器负坐标、移除屏幕与 DPI 边界。可选原生窗口测试验证真实调整、最大化、恢复、关闭和重新打开后的位置尺寸。
