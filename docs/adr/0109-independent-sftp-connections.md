# 独立 SFTP 连接与生命周期

保存的 SSH 服务器配置可通过会话管理器右键“打开 SFTP”，或选中配置后使用主工具栏 SFTP 直接打开。终端上的 SFTP 入口也创建独立认证连接，复用保存的路由、账号、凭据库和主机验证，但不分配 PTY、不启动 shell、不创建终端标签或日志。服务器仅允许 SFTP 子系统时仍可连接。

SFTP 顶栏提供断开和重新连接，明确区分连接中、已连接、断开中、已断开及通信失败后的状态未知。断开后保留主机身份，但降低颜色、禁用远端操作。连接成功自动读取队列、认证主机身份和两侧目录。关闭独立窗口会断开自己的 SFTP，SSH 终端不受影响；关闭终端也不影响 SFTP。GUI 子窗口销毁和后台退出都有独立连接清理。

协议 minor 60 增加 SFTP 操作 ConnectProfile(47)、Disconnect(48)、ConnectionStatus(49)。ConnectProfile 的 document_json 仅携带 ProfileId，session_id 是本轮新 UUID；后两者不携带额外字段。连接和状态回复使用 SftpConnectionInfo（会话、配置、标题、认证主机、在线状态）。客户端先检查协议版本，后台仍校验能力、请求形态、UUID 冲突、64 个独立连接上限和凭据库认证 epoch。

后台将已有终端和独立 SFTP 适配成稳定 Arc 身份的 SftpTarget，原有目录游标及传输任务继续绑定原连接对象。独立连接不出现在终端 SessionList 中。SFTP Disconnect 拒绝终端 UUID，重复断开已移除连接是幂等操作。

断开先阻止新任务、取消活动传输、持久暂停队列并释放目录游标，再关闭自己的目标和跳板连接。重连先确认旧连接已关闭，再使用新 UUID 连接；未确认关闭的旧 UUID 保留待清理，不继续创建新连接。进行中的连接只接受关闭意图，不排队重复连接；关闭意图在认证结束后执行，不再加载目录。旧任务保留于历史，需检查并显式迁移/恢复，不会自动重试结果不明确的任务。

未知主机复用既有指纹确认弹框；确认后只重试 SFTP，不创建终端。已变更或撤销的密钥仍被拒绝。

验证使用私有临时配置和本地 SSH/SFTP 服务器，覆盖拒绝 PTY/shell 的账号、目录读取、幂等断开、新连接 UUID、稳定游标身份、SSH 双向隔离、未知密钥与协商拒绝；前端认证 IPC 验证连接/载入/断开/重连顺序、重复点击、连接中关闭和旧连接断开失败的清理引用；实际控件测试覆盖无终端的入口及小窗口顶栏状态。


重连开始后，排队的旧会话命令和迟到的目录、队列、传输及工作区错误回复不得切换当前会话、覆盖新目录或撤销新连接的操作权限。客户端以独立连接 UUID 隔离请求接收、worker 分发和回复发布，旧命令直接丢弃；针对迟到成功及失败回执均有回归。后台退出并发清理独立连接，逐连接最多等待 3 秒，避免连接数量放大退出耗时。
