# 高频工作流、快捷操作与 SFTP 编辑

本轮面向操作流程、界面成熟度、键盘效率与 SFTP 工作流收敛现有功能入口。无新增 SSH 协议或后台保存语义。

## 快捷操作

菜单右侧和工具菜单提供“快捷操作”，Ctrl+Shift+K 打开搜索面板。支持中文名称与英文关键词、方向键、Enter、Esc，执行既有 WorkbenchMenuCommand。操作依据当前连接状态禁用，不另建 SSH/SFTP 分发路径。鼠标渠道复用与重连条件沿用工具栏；面板不提供直接发送 shell 文本的能力。

面板可从普通编辑框打开，关闭时恢复原焦点与草稿；认证、凭据、发送确认等模态流程隔离输入。搜索内容与 Enter 在同一帧到达时按最新结果执行；IME 组合或提交文字不触发执行。打开后同步输入暂停，按键、鼠标与滚轮不会进入终端。

## 键盘设置

工具菜单与全局设置可进入“键盘快捷键”。仅配置应用动作的 Ctrl+Shift+字母，空白禁用；不提供终端原始按键重映射。固定保护 K（快捷操作）、P（标签列表）、C/V（复制粘贴），F 保留给查找。重复、非法组合不能保存。

默认：N 新建 SSH 配置，O 会话管理，F 查找，E SFTP，R 重连，G 快捷命令，T 隧道。Windows/Linux 使用 Ctrl；支持 Command 的平台按同一应用修饰键约定映射。普通文本框保留自己的编辑快捷键。

设置保存到显示设置同目录的 workbench-shortcuts.json，各窗口在进程内即时共享。验证通过后先写入并同步临时文件，再原子替换；保存失败保留原活动文件和内存设置。没有会话、用户名、密码或命令内容。

## 界面与反馈

工作台与终端右键菜单使用统一的整行命中区域。工具菜单中的恢复操作合并到高级设置，小窗口主菜单不溢出。操作提示从状态栏短文本提升为可关闭的提示条，提供详情、复制和适用时的重连入口。SFTP 错误提供就地刷新目录 / 队列与折叠详情。

## SFTP 编辑

远程普通文件可通过工具按钮、右键“编辑文件”或 F4 直接打开。直接进入编辑页，显示路径、编辑状态和修改提示，技术详情与外部编辑器设置折叠；小窗口自动缩短正文高度，常规保存按钮保持可见。新文件不会覆盖未保存草稿。

“保存并上传”或 Ctrl+S 是明确的用户提交动作，去掉重复勾选；仍发送原 EditSave 的原子替换授权，后台保留原摘要冲突检查、独占发布与原文件备份。没有修改时不创建传输。保存发出后锁定重复提交，真实版本或失败回执返回后才允许下一次。当前新草稿、过期基础版本和未知结果不会静默覆盖；已准备的旧保存意图通过明确的“继续上传已保存版本”恢复，Ctrl+S 不重放它。

高级恢复中保留重新读取、会话绑定和关闭记录；丢弃草稿需明确勾选。上传继续沿用原队列及取消、暂停、冲突和清理规则。

自动验证覆盖真实控件、同帧搜索、IME、原子设置保存、SFTP 保存与重复提交保护及小窗口。固定离屏预览不等同于真实 SSH 长期使用验收。
