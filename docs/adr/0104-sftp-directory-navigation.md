# SFTP 目录导航

本地与远程文件栏采用可点击面包屑，点击编辑按钮或 Ctrl+L / Alt+D 切换为路径输入；输入框默认全选，Enter 或“转到”提交，Esc 取消。长路径保持单行水平滚动，窗口宽度不由目录文字决定；下拉列表继续提供上级、最近访问和子目录。

每侧分别保留最多 64 个成功加载的目录。Alt+Left / Alt+Right 前进后退，Alt+Up 上级，F5 刷新；快捷键作用于当前点击的文件栏，初始为远程栏，菜单打开时不截取快捷键。失败请求、刷新和分页不新增记录，后退后访问新目录会清除前进分支。导航历史不跨窗口会话恢复。

星形菜单支持收藏当前目录、打开收藏和移除收藏，Ctrl+D 收藏或取消当前目录。收藏保存在现有 sftp-settings.json，保持旧版本默认本地目录兼容，原子写入且互相保存时不覆盖另一类设置。本地收藏全局共享；远程收藏按经过验证的服务器、端口、账号、主机密钥及连接路由隔离，身份未加载时不能添加远程收藏。每个范围最多 32 条、总计最多 128 条，设置文件上限 1 MiB。

验证覆盖原生 Windows 盘符与 UNC 根目录、POSIX 路径、输入框全选/提交/取消、鼠标“转到”、两侧历史隔离、失败与分支切换、收藏持久化及旧设置兼容，以及 720×480 到大窗口的布局。文件传输协议与后台无需变更。
