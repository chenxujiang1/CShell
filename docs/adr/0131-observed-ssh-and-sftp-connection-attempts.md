# SSH / SFTP 连接阶段诊断

日期：2026-10-27。用户确认优先完成连接诊断与分阶段进度。

## 可观察范围

覆盖保存配置的 SSH 连接、手动重连、终端配置确认后连接、复制 SSH 通道、独立 SFTP 和复用 SSH 打开 SFTP。自动断线恢复继续使用原有会话恢复状态，不把后台恢复伪装成本轮主动创建尝试。

阶段来自实际执行点：准备凭据、本地 DNS、TCP、代理协商、每级跳板的连接 / 认证、SSH 握手、主机密钥验证与完成握手、认证、等待人工输入、终端通道、PTY、Shell、SFTP 通道 / 子系统、初始目录和就绪。IP 地址直接连接时不补造 DNS 阶段；代理 / 跳板的目标解析发生在远端，不报告虚构的本地解析耗时。DNS 与 TCP 仍共用原来的整体连接超时。

主机密钥回调在 russh 的另一任务中执行，显式捕获观察器；其余步骤使用连接尝试内的任务局部观察器。没有观察器的原有调用不分配诊断记录，不改变认证顺序、主机信任决策或凭据使用。等待密码、动态码及凭据库解锁与实际认证分段计时，不保存提示、答案、密码、私钥或服务端横幅。

## 协议与资源边界

IPC minor 77。SessionCreateRequest、TerminalContextLaunchRequest、SFTP ConnectProfile 增加可选 connection_diagnostics 标志，默认 false，不改变旧消息编码。GUI 仅在协商 minor 77 后启用。服务器在实际分发前清除此传输层标志，原有规范请求校验保持不变。其他 SFTP 操作不能请求诊断。

启用时，在原连接的最终响应前发送 ConnectionDiagnosticUpdate；所有中间和最终响应绑定原 request_id。每次尝试另有唯一 ID，客户端校验 ID、时间单调性、阶段状态、大小和行数，拒绝混入其他尝试的进度。最终响应仍决定连接是否创建成功，不根据中间阶段推断已连接。后台报告就绪后仍等待最终回执；若此时回执丢失，界面标记结果未确认，不保留成功显示。

诊断最多 128 行。超过上限时保留最初阶段及当前 / 最终阶段，明确标记省略；端点最多 320 字节，IPv6 使用方括号。服务器使用 latest-only watch 合并进度，无无界事件队列。客户端限制单次诊断文档为 96 KiB、更新次数为 4096，沿用连接请求超时。

服务器每两秒发送计时心跳，进度写入最多等待五秒。关闭 IPC 客户端后可终止仍在等待的连接 future，释放待输入认证和已打开的连接资源；已经提交但最终回执丢失仍保持结果未确认，不能宣称远端会话一定未创建。心跳与阶段消息都从同一记录器取最新快照，避免时间倒退。

## 界面与操作

SSH 主界面和 SFTP 显示可展开时间线、当前阶段、阶段耗时、总耗时与跳板 / 端点。进行中自动展开，成功后切换为默认收起的“最近一次建立耗时”；后续断开不会仍宣称连接在线。失败显示对应排查建议和显式重试按钮；结果未确认不提供诊断栏的重试按钮，先检查会话状态。不会自动进入配置编辑器。

重试复用既有 SSH / SFTP 分发及当前标签，不新增独立连接实现。诊断不保存到磁盘；关闭标签即释放其视图。可主动复制经过限定字段构成的诊断，包含主机 / 路由端点元数据，供排障使用。SSH 按启动代次与当前运行会话隔离进度，SFTP 按本次 session ID 隔离；旧尝试不能覆盖新尝试。

沿用默认 target、固定日志与预览、唯一试用 bin。运行中的程序不覆盖、不停止用户会话。没有安排长期体验验证。
