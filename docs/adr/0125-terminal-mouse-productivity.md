# 终端鼠标效率增强

在已有选择复制、中键粘贴和右键菜单之上，补齐以下操作。

- 拖选抵达上下边缘时自动滚动；滚轮浏览历史保留选区。选择以后台原始行 ID 和列定位，跨页面保存原文，保留软折行、中文及组合字符。缓存限制 16 MiB；页面缺失或超限时明确提示，不复制不完整内容。页面加载未推进时不堆积滚动请求。
- 服务器程序启用鼠标后，点击、拖动和滚轮按 xterm 1000 / 1002 / 1003、传统 / UTF-8 / SGR 编码发送到当前会话。鼠标事件不参与多目标键盘同步。Shift 强制本地选择、滚动和菜单；切换标签、失焦或打开阻塞对话框时释放远端按键。
- 右键可查找选中文本、打开或复制 HTTP(S) 链接；Ctrl＋左键也可打开链接，悬停显示提示。仅允许 HTTP(S)，不执行终端文字或 shell 展开。查找暂时隐藏命令栏，保留草稿和目标。
- 对远程绝对路径提供 SFTP 定位与下载，复用已有会话、目录列表及传输队列。待处理动作绑定来源会话及目录请求，切换或重连后不执行旧操作。相对路径和波浪号路径不猜测解析。
- Ctrl＋滚轮按每格 2 px 临时缩放当前窗口；Ctrl＋0 或点击状态栏临时字号恢复全局默认，不修改持久设置。
- 全局“鼠标与剪贴板”中可编辑双击单词分隔符；默认保留路径、主机和地址中的常用字符。三击选择当前快照中由软折行连接的整条逻辑行，Alt 拖动仍为矩形选择。

IPC minor 升为 72，新增鼠标输入消息、鼠标模式、屏幕起始行 ID 和历史行软折行标记。GUI 与后台一起更新；未提供字段时使用关闭鼠标及无折行的兼容默认值。

验证包括编码与模式解析、完整帧与增量帧往返、跨页 Unicode 选择、缓存和加载停顿限制、SFTP 操作失效、URL 输出命令、搜索草稿保留、实际字号控件及离屏菜单布局。真实 SSH 上 Vim/tmux 的长期交互仍需人工验收。
