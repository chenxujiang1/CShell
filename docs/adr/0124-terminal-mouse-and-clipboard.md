# 终端鼠标选择与剪贴板

默认选中后复制，中键粘贴，右键打开菜单。全局设置的“鼠标与剪贴板”页可关闭自动复制、中键粘贴或启用右键直接粘贴。Shift＋右键始终打开菜单。偏好保存在显示设置旁的 `terminal-clipboard.json`，在进程内即时共享给所有窗口；会话统一使用全局偏好。

- 左键拖动选择；双击选择单词（包含路径、地址），三击选择显示行；Alt 拖动矩形选择；Shift 点击扩展选区。自动复制在释放左键时发生，单击或清除选区不写剪贴板。
- 复制为 Ctrl＋Shift＋C / Ctrl＋Insert，粘贴为 Ctrl＋Shift＋V / Shift＋Insert。按住键不会重复粘贴。终端保留 Ctrl＋C/V 控制键，文本编辑框保持普通编辑快捷键。
- 选区固定一份有界快照，画面提示暂停更新；最新输出仍持续接收。单击、Esc、输入、滚动或调整窗口/字号恢复实时画面。标签切换与跨窗口移动保留选区，连接重建清除旧选区。
- 历史视图按原始逻辑行的折行片段生成选择快照，保留中文、宽字符和组合字符。普通复制连接自动折行、保留真实换行并去除行尾补齐空格；矩形复制保留列和空格。
- 终端 Cell 增加自动折行标记；IPC 协议 minor 71、protobuf TerminalCell tag 6，未发送此字段时默认 false。需要新版后台才能提供实时屏幕的折行标记，旧端仍可正常收发。
- 键盘、中键、右键共用粘贴入口和大小限制。单行无控制字符时直接粘贴；包含换行/控制字符时复用居中、带行号、固定底部按钮的命令预览，不追加 Enter，不改写原始内容。
- 普通粘贴固定当前会话；明确启用实时同步时使用控制器冻结的目标及既有确认、身份、状态和有效期检查。取消、Esc、关闭预览不发送内容，恢复终端焦点。
- 右键菜单提供复制、粘贴、载入多行编辑器；复制不可用时禁用。编辑器已有草稿时不覆盖，提示先处理草稿。手工复制粘贴与远端 OSC 52 剪贴板授权策略独立。

验证包括真实 PTY 回归、多标签及跨窗口状态、历史和实时折行、矩形空格、中文宽字符、快捷键冲突、菜单边界、全局设置小窗口，以及命令/粘贴预览在 100%～200% DPI 下的布局。
