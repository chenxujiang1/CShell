# ADR-0081：密码编辑反馈与会话终止结果

- 日期：2026-10-15

## 问题与修复

密码控件原先对任意非空内容固定绘制八个圆点，无法反映继续输入、退格或
光标位置。现在每个 Unicode 字符绘制一个圆点，显示真实编辑光标，支持
横向滚动、点击定位、方向键和 Ctrl+A 替换。控件只分配一次交互区域，
并校正 UTF-8 光标边界。继续避免将明文放入 egui 排版、辅助功能或撤销历史，
输入事件在处理后清零。

终止确认原先点击后立即消失；工作区保存暂停时，菜单分发还会丢弃终止
动作。现在进程终止独立于布局写入权限，明确等待后台确认；失败保留弹窗
和原因供用户检查、重试。暂停期间只删除运行时会话绑定，保留保存的布局。
终止排队期间禁止其他连接动作覆盖 watch 通道里的请求。

IPC 连接和握手分别限制为五秒；关闭请求及后续会话列表确认共同限制为五秒。
仅在后台确认且目标已从列表消失后报告终止成功。失败或结果不明时清除等待
状态并刷新列表，不自动重发终止请求。普通视图关闭失败也会解除标签关闭
等待状态并显示提示。

## 验证

- 密码逐次输入、中文、光标中间插入、退格、Ctrl+A 替换与明文隔离。
- 隔离的真实本地进程：移除保留会话、拒绝失效目标、暂停布局时终止当前
  会话并保持已保存布局不变。
- 模拟后台不回复，以及回复确认但列表仍有目标：显示失败且不自动重发。
- 连接设置密码保存流程、工作台控件与窄窗口布局回归。

使用默认 target 和唯一试用程序目录，不触碰用户已有进程、配置或密码。
