# ADR-0092：SFTP 默认目录、三并发与批量传输

- 日期：2026-10-16

本地文件列表提供“默认目录”菜单，可以输入绝对路径或使用当前目录，保存后
下次打开 SFTP 使用该文件夹；留空恢复当前用户目录。设置独立写入数据目录
的 sftp-settings.json，采用临时文件和原子替换，不改动显示设置、连接配置
或凭据。无效路径不覆盖已保存设置；已删除目录或损坏设置回退到用户目录。

浏览器批量入队在同一次版本校验操作中，为没有显式并发设置的队列设定三并发。
最多三个文件运行，第四个等待空位；已有明确队列设置保留。原有不同目标、
校验传输及会话身份校验继续生效，不允许并发覆盖相同目标。

性能检查发现旧托管传输每 32 KiB 要依次完成本地读取、写前队列快照持久化、
远端 WRITE 回执、远端 fsync（下载则本地同步）和写后队列快照持久化。
队列快照本身还需要写临时文件、sync_all 和原子替换。三文件会争用同一队列
日志锁。这使吞吐被磁盘同步与网络往返次数限制，而非仅由内网链路带宽决定。
源文件及临时目标的完整 SHA-256 校验还会额外读取文件。

托管复制改为最多 1 MiB 的持久检查点，每批仍先保存 Write intent/write_end，
等待所有写入回执并同步目标，再保存已确认字节及前缀摘要。每 MiB 的目标
同步由 32 次降为 1 次，写前/写后快照由 64 次降为 2 次；完整摘要、原子
发布、默认不覆盖目标、恢复前对比临时文件内容均保留。旧 32 KiB 检查点
继续有效；write_end 仍必须位于内容范围内且最多超前 1 MiB。

每个文件最多 16 个原始 SFTP 请求在途；单个网络包仍最多 32 KiB 并尊重
服务端更小的包和操作上限。读取按偏移拼接、补足短读，写入按偏移确认；
批次错误返回前排空回执。生成 future 和缓冲区按窗口推进，不随小包数量
预先分配所有请求。完整校验读取也使用流水线，避免校验阶段再次退化为
每包一个网络往返。受限速的传输使用较小批次，按本批末尾字节计算等待，
保持首次传输限速及暂停响应。界面区分准备、复制、校验和提交阶段。

验证包含默认目录持久化/无效编辑/损坏回退、窄窗口布局、短读和乱序回执、
错误批次后的通道可用性、边界限制、旧与新恢复记录校验，以及四文件竞争
三个槽位的真实本地 SSH 上传/下载和最终逐字节一致性。带模拟回执延迟的
测试用于证明流水线消除逐包等待，不代表用户实际内网服务器的测速结果。

构建复用默认 target，试用版只原位更新既有 bin，不保留额外二进制副本。
