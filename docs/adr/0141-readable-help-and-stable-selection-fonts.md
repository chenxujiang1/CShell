# 0141：帮助页阅读样式与选区字体一致性

日期：2026-11-13

## 问题与原因

帮助页继承运维工作台的紧凑 13 px 字号，快捷键与解释逐行混排；关于页也缺少阅读层级。两个入口保留在“帮助”下同级，分别显示独立页面。

实时终端的普通 ASCII 使用 Hack 预生成字形，历史渲染却始终调用 cosmic-text / Swash。选择文字后滚动、拖拽自动滚动进入历史时，字形覆盖率、字形偏移和基线可能改变，表现为字体变化。历史选区还会将原有 ANSI 前景色替换成亮白色，而实时选区只叠加背景。

## 决定

帮助对话框使用局部阅读样式：标题 22 px，分组标题 16 px，正文 15 px，辅助文字与键位 14 px。正文采用高对比度文本色；背景不透明，按主题分组卡片，快捷键使用独立键位标签。宽窗口左右排布键位与解释，窄窗口上下排布，关闭按钮始终位于滚动区域外。快捷键优先显示当前系统的默认绑定。关于页展示版本、用途、使用帮助及复制版本信息入口。

样式限定于帮助对话框，不修改全局工作台或终端字号。

字形绘制统一到同一入口：实时单元格和历史字素中，普通单列 ASCII 均复用同一个预生成字形；粗体、斜体及 Unicode 保留原有塑形和回退路径。历史选区使用与实时相同的主题背景叠加，保留 ANSI 前景色，不改变字形、字号或粗细。搜索与光标的高亮语义仍按各自原有规则处理。

## 验证

新增实时、历史、选中、取消选区对比，覆盖 12 / 18 / 28 / 40 px，深浅主题，ASCII、ANSI 彩色与粗体、中文、组合字符、斜体；逐一比较实际字形顶点、纹理 UV、位置与前景色。临时恢复旧 ASCII 分流时，这一回归稳定失败；恢复修复后通过。该复现只修改测试期间的本地源码，随后逐字节恢复，不操作用户窗口或服务器。

帮助页用生产中文字体生成固定离屏预览，核对常规与 640×480 窗口；自动布局检查同时覆盖两个页面及多种缩放，另验证实际排版的正文达到阅读字号、全局字体样式保持不变。
