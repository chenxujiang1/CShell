# 0117：全局 SSH 密钥对管理

主页面工具栏增加“凭据管理”，窄窗口在“更多”中保留入口；“工具 → 凭据管理…”始终可用。无需先打开 SSH 配置。窗口分为“密钥对”和“凭据库与连接设置”，保留现有主密码、系统钥匙串、连接凭据模式功能。

密钥库独立于 Profile。支持导入现有私钥，自动提取公钥；可附带 `.pub` 文件校验配对。支持生成 Ed25519 / OpenSSH 密钥对，用户可选择设置或不设置私钥口令，设置时需要两次匹配。导入沿用输入口令重新编码为 OpenSSH 格式。列表展示名称、算法、口令状态、SHA256 指纹和公钥；复制按钮仅复制 authorized_keys 格式公钥。

导出到用户指定的新目录，生成 `id_key` 和 `id_key.pub`，保留私钥口令设置。目录或文件已存在时拒绝覆盖。可在 SSH 配置中选择导出的 `id_key` 使用该密钥。导出不修改服务器，也不自动安装公钥。删除库内记录不删除导出文件或服务器公钥。

## 存储和边界

- IPC minor 67，新增密钥请求参数及公开元数据字段，旧后台被客户端明确拒绝。私钥内容不经过 GUI/IPC，不进入剪贴板或 Debug；口令沿用可擦除的 secret 字段。
- 加密 Vault 新增 ManagedKey 记录类型，使用独立 UUID 和固定版本化 binding。记录包含名称、公钥、指纹、OpenSSH 私钥及口令，整体通过现有 AES-GCM/Vault 事务加密保存。重启后先锁定；主密码轮换沿用现有记录重加密机制。
- 解锁后最多管理 32 个密钥，受现有 128 记录、1 MiB 文件总容量约束；单个输入文件最多 64 KiB，口令最多 1024 字节。OpenSSH bcrypt 预检限制在 1～128 轮、盐不超过 64 字节；PPK 沿用现有有界解码器。旧版加密 Profile 迁移包不包含全局密钥库，密钥对通过独立导出功能迁移。
- 生成、文件读取与编解码在后台阻塞工作线程进行。开始前检查解锁、Vault revision、lock generation，最终提交或导出再次检查；锁定使旧请求失效，冲突不会自动重放。
- 导出先创建全新目录，应用现有当前用户私有目录权限，再创建文件；Unix 私钥为 0600，Windows 文件继承受保护目录 ACL。磁盘写入失败明确报错，可能留下不完整的新目录，重试须使用新目录名，不覆盖旧数据。
- GUI 显示处理中状态并禁用重复提交。凭据窗口打开时阻止终端接收表单按键。界面关闭、失焦或锁定时清空临时口令。Windows 中仅在本进程原生文件选择器处于前台时延迟工作台失焦锁定；切到其他进程或选择器结束而主窗口未激活时恢复锁定。系统锁屏/桌面会话保护一直由 daemon 执行。其他平台沿用保守失焦锁定。

## 验证

覆盖生成有口令/无口令密钥、配对校验、错误口令、公钥复制、协议脱敏、异常 KDF、导出再导入、重启后解锁读取、不覆盖已有文件、锁定及陈旧请求拒绝操作，以及实际字体下的小窗口表单布局。复用默认 target 和现有唯一试用目录，验证记录复用固定文件名。
