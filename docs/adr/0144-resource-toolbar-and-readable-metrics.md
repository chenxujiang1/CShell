# 0144：服务器资源工具栏入口与指标阅读布局

日期：2026-11-13

## 入口

在连接工具栏的 SFTP 右侧常驻“资源”按钮，宽窄工具栏均直接可见，沿用“查看 → 服务器资源”的同一命令。只对当前标签的已认证 SSH 会话启用；连接操作繁忙或工作区暂停时禁用。左侧选中的其他服务器配置不会改变采集目标。

面板标题下展示当前标签的配置名称和配置目标；明确以“配置”标注，不把可编辑的配置地址冒充运行中会话的不可变身份。名称过长时截断并提供完整悬停提示。实际采集仍绑定当前 SSH session。

## 展示

正文与操作控件使用局部 15 px 字号，辅助文字 14 px，关键数值 28 px；不改变全局工作台和终端字体。CPU、内存、Swap、平均负载和运行时间各自分组。CPU 与内存、Swap 提供数值及用量条；负载按 1/5/15 分钟分行，保持其原有数值含义，不换算成 CPU 百分比。内存与 Swap 明确显示已用量、总量及单位。

足够宽时指标分两列，窄面板纵向排列。常规窗口增大初始高度；刷新设置固定在顶部，UTC 采集时间、快照状态和关闭入口位于指标滚动区外。高度预算包含标题栏与边距，并显式设置最小滚动高度，避免 egui 默认 64 px 下限挤出小窗口操作控件。

CPU 缺失显示暂不可用，不伪造 0%；Swap 总量为零显示未启用。刷新出错且仍有旧数据时明确标识上次成功快照；刷新进行中也说明当前展示的是旧结果。默认只保留单次内存快照，不增加历史图表或落盘。

## 采集约束

保留既有打开时采集一次、自动刷新默认关闭且间隔为 0、显式开启后最短 5 秒、隐藏或最小化暂停、切换会话清理旧结果、错误停刷的行为。没有修改后台采集脚本、缓存、并发、SSH 通道或协议，没有新增服务器请求或存储。

## 验证

工具栏真实点击测试验证当前已认证会话及繁忙状态，边界测试覆盖 720/900/1280 宽度和多种缩放。生产中文字体离屏预览核对工具栏、常规窗口、小窗口及错误状态；指标测试覆盖百分比、单位、已用内存计算、CPU 缺失和 Swap 未启用。480×320、720×480 与常规窗口验证固定操作区和全局样式隔离，极大数值与长目标名称不挤出窗口。旧刷新调度测试继续保留。

仅更新固定 Windows 试用目录；相关验证不等于 Mac 实机或完整远程 CI。未提交或推送。
