# ADR-0079：已打开会话移除与新建 SSH 密码输入

- 日期：2026-10-15

## 修复

已打开会话每行提供移除按钮和右键菜单。移除复用终止确认窗口，固定目标
SessionId，不随当前选择变化；后台仅接受当前或已列出的会话。确认后执行
明确终止并从 daemon 注册表移除，保存的 Profile 保留。关闭标签另走原有
view-close 策略。收尾按被移除会话查找绑定标签；移除无绑定标签的保留会话
后重新附着原终端，避免工作台停留在已断开的视图。

新建 SSH 的密码框始终可编辑。填写密码后点击“保存配置”，桌面线程提交
一个带 Zeroizing 密码的后台命令；后台先以预期版本保存普通配置，再校验
返回的 SSH 目标与提交目标完全一致，以返回的新版本调用原有 SetPassword。
密码不进入 Profile 配置、命令 Debug 或导出内容。两个请求不是数据库原子
事务；若密码步骤失败，明确显示“配置已保存，但密码未保存”，供用户重新
填写并保存。现有目标被编辑时，独立“保存密码”仅对匹配的已保存目标启用。

## 验证

- 工作台指针点击：移除固定行目标、取消无副作用、原有标签和菜单回归。
- 新建 SSH：未保存时点击密码框、实际输入、点击保存并检查组合命令。
- 凭据请求：使用保存后的版本；目标变化时拒绝转移密码。
- 移除命令：接受已列出的非当前会话、拒绝未知会话、不误用当前 SessionId。
- 复核连接设置及其他辅助面板的窄窗口布局，构建 Windows GUI。

本轮不以真实用户密码和远端主机进行连接测试。
