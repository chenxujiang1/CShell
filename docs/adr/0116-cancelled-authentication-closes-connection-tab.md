# 取消认证即结束本次连接

用户在账号、密码或键盘交互动态码弹框中取消连接，属于主动取消，不应进入配置修复流程。原实现将 AuthenticationCancelled 映射为 AuthenticationRejected，所有启动错误又会自动打开配置窗口，待连接标签也只解除 busy 而未移除。

IPC minor 66 增加 SessionFailureCode.AuthenticationCancelled（13）和 SftpStatus.Cancelled（8）。后台只对实际的 SshError.AuthenticationCancelled 返回该状态。密码错误、超时、网络失败和结果不确定继续保持各自错误，不通过包含 cancelled 的任意文字推断取消。新版桌面对旧后台的固定取消提示做精确兼容。

SSH 取消结果走独立的 LaunchCancelled 处理，不产生配置错误，也不自动重试或创建本地替代会话。前端收到确定取消后，只移除当前待连接且配置匹配、没有运行时绑定的标签，清理对应视图后回到其余标签；最后一个标签取消后保留空工作区。已经绑定进程、仍在创建、配置不匹配或旧回复不会触发此清理。手动重连已先关闭旧运行时，因此重连认证取消同样移除其待连接标签。

SFTP 取消被标记为确定断开，不再显示状态未知。每个主机连接独立产生一次性取消事件，前台和后台标签均按其自身 ID 移除，其他主机、公共本地文件栏和 SSH 终端保留。切换和关闭标签期间暂停处理新的自动关闭，避免递归清理改变索引；最后一个取消标签不会再次打开空 SFTP 窗口。

首次主机密钥确认的取消、Escape 和扫描阶段取消同样结束由该确认等待的连接标签。会话编辑器中手动预览密钥只是预览，关闭预览不关闭已有标签或连接。配置标识、当前连接身份及无运行时绑定的条件保护无关会话。

网络错误和最终认证失败、超时保留失败标签与错误详情供重试，不再强制打开配置编辑器。明确的配置 / 凭据问题仍可提示配置操作，首次主机密钥继续使用独立指纹确认弹框。

取消答案不携带已输入的密码、动态码、用户名或保存凭据选择；原有秘密缓冲清零。取消提交期间按钮禁用，重复点击不再重复提交。取消请求无法发送或连接结果不确定时保留必要错误反馈，不把未知结果当作已经关闭。

验证包括真实 MFA SSH 及独立 SFTP 的取消状态、取消 OTP 后不继续密码认证、不建立后台会话以及新一次连接仍可成功；桌面实际取消按钮与 Escape、工作线程不重放创建请求、精确取消与普通错误区分、多 SSH / SFTP 标签隔离、全部 SFTP 标签取消与重入保护、主机密钥预览和确认取消语义。
