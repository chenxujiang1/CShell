# 0142：拖拽上传失败后的任务移除

日期：2026-11-13

## 问题与原因

终端拖拽上传将失败、取消和成功都归为已结束状态，界面只对未结束状态显示“取消上传”。失败记录默认保留，因此失败后没有任何可用的任务移除操作。后台取消接口也会跳过已结束任务，单纯显示取消按钮无法清除记录。

## 行为

对已确认失败、已取消和已成功的任务提供“移除任务”按钮。点击后只从本地进度列表移除对应的记录，清除该记录的关注标记；最后一条记录移除后关闭空进度窗口。不发送取消、重试或文件删除请求，不删除已上传文件，也不影响其他任务。

移除前在锁内再次检查任务标识、原 SSH 会话和最新状态。进行中及结果未确认的任务仍使用真实的“取消上传”，并保留记录直至后台确认。关闭进度窗口仍不取消传输。后台已结束记录继续使用现有有界缓存，不修改协议或后台任务生命周期。

## 验证

先运行真实 UI 点击回归，在原界面稳定复现“移除任务”按钮缺失；修复后覆盖 SFTP 与 ZMODEM 的失败、取消和成功记录，小窗口按钮可见与可点击，最后一条记录移除后不再重新弹出。检查未结束及通信结果未确认时仍向原会话、原任务发送取消请求，且本地移除不产生远端操作。另验证来源不匹配、未知任务结果及其他运行中任务不会被误移除。
