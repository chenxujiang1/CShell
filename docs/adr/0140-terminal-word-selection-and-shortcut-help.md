# 0140：终端选词、全选与独立快捷键说明

日期：2026-11-13

## 操作规则

普通单击只聚焦并清除旧选区；拖动按字符选择。双击选择一个技术词，双击后拖动按词扩展；三击选择完整逻辑行，包含自动折行，三击后拖动按行扩展。第四次点击开始新一轮，不自动全选。Shift 单击明确扩展选区，Alt 拖动使用矩形选区。滚轮、拖动、失焦、切换标签及点击终端以外区域打断连击。

默认 `/`、反斜杠、冒号和标点分隔单词；保留文件名中的点、横线及下划线。严格预设额外分隔点和横线；用户自定义分隔符不被默认规则迁移覆盖。原有两代默认分隔符升级为新默认。中文使用内置 ICU4X 字典，也可在鼠标与剪贴板设置中改为按字选择；不请求网络，不记录分词内容。Emoji 和组合字符按完整字素选择。

完整路径、URL、地址通过右键显式选择或复制，不改变普通双击含义。菜单保存选区的帧，持续输出不能使菜单操作变成复制其他文字。

## 全选与持续输出

右键提供选择当前屏幕、全选当前终端、导出当前终端。Windows/Linux `Ctrl+Shift+A`、Mac `Command+A` 在终端拥有焦点时全选；编辑框使用自己的快捷键，Shell 的 `Ctrl+A` 保持原意。按键释放与被消费的按下配对，避免增强键盘协议收到孤立释放。

全选固定当前会话的屏幕内容与结束行，后台通过已有鉴权本地 IPC 分页读取仍保留的 RAM 历史，不向服务器发送命令或输入，不默认落盘。后续 tail -f 输出不加入选区。页面范围校验会话、请求 ID、行号连续性和保留范围；截断行单独重读，无法完整读取时明确失败，不返回残缺复制内容。软折行保留必要空格，不插入换行；真实换行保留。

复制上限 16 MiB，超限提示导出，不静默截断。仅用户明确导出时弹出保存窗口，流式写入所选目录中的临时文件，完成并核对会话后替换目标文件；失败取消会清理临时文件。导出上限 256 MiB。已完整选入内存的内容导出时复用同一份文字。读取最多两个并发任务，单页超时 3 秒，总读取超时 60 秒；新选择、切换标签、连接代次或布局变化取消旧任务。

## 帮助入口与边界

“帮助 → 快捷键说明”与“帮助 → 关于 CShell”同级，为独立模态页面。内容滚动，关闭按钮在滚动区域外；说明默认鼠标、复制粘贴、全选、控制键及阅读操作。打开帮助时终端键鼠与输入法提交被阻断。

按段落或命令输出块选择仍需要可靠命令边界；不根据空行猜测，也不把三击扩展为整个缓冲区。

## 验证与限制

固定验证日志及报告使用 `artifacts/ui-refresh-20261015/logs/selection-help-*`。测试覆盖技术词、JSON、中文、Unicode 字素、逻辑行、历史分页与单行重试、冻结结束点、帮助入口和缩放布局。Windows 原生窗口与渲染检查沿用项目现有隔离测试入口，不操作用户会话。Mac 的真实鼠标与输入法体验仍须实机验收。
