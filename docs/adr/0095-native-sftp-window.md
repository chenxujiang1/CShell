# 0095 — SFTP 使用独立原生窗口

原实现通过 `egui::Window` 将 SFTP 绘制在终端工作台的渲染表面内，尺寸、拖动范围和最大可用区域都受 CShell 主窗口限制。

SFTP 现在创建无父窗口/所有者约束的 winit 顶层窗口，具有独立的系统标题栏、输入状态、DPI、egui 上下文与渲染器。它可以移出主窗口、移到其他显示器、单独缩放或最大化。主体直接占用其独立窗口内容区，不再套内部对话框。

每个工作台窗口至多维护一个 SFTP 窗口，重复打开会聚焦并复用；打开时绑定当前 SSH 会话，终端标签切换不改变传输对象。标题显示关联会话。显式从另一个 SSH 会话再次打开 SFTP 时，改为该会话。文件操作仍通过原有后台和持久队列执行。

关闭 SFTP 只关闭文件界面，SSH 终端和传输任务继续运行。关闭所属工作台窗口时释放其 SFTP 窗口；退出 CShell 时统一释放窗口和进程级后台生命周期连接，沿用 ADR 0094 的后台清理行为，不产生独立 GUI 进程。创建或渲染失败会记录诊断；设备恢复重建纹理，避免抛弃未处理纹理差量导致 panic。

验证包括：原有桌面测试、三个独立视口尺寸下的全部 SFTP 页面布局，以及显式运行的 Windows 原生窗口测试（尺寸大于主窗口、独立位置和最大化、设备丢失恢复、关闭路由、重开与退出后资源释放）。原生测试使用合成目录，不读取用户凭据或连接真实服务器。

后续体验建议按优先级安排：

1. 导航：可编辑面包屑、收藏目录、返回/前进与键盘导航，并按连接记住远端常用目录。
2. 文件操作：Ctrl/Shift 多选、统一右键菜单、F2 重命名、创建目录、属性和权限入口，减少在高级页切换。
3. 文件表格：可调整和记忆列宽、左右栏比例、文件筛选和隐藏文件开关，窗口位置/尺寸记忆。
4. 传输区：运行/等待/完成/失败筛选、批量暂停恢复、失败原因和重试入口，整体速度与剩余量汇总。
5. 视觉层级：突出主机和传输方向，统一工具栏和图标密度，弱化低频管理选项并强化焦点/拖放目标反馈。

这些建议是后续设计方向，本轮只落实独立窗口及必要的生命周期和渲染处理。
