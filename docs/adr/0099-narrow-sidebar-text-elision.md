# 0099 — 窄侧栏文字省略

侧栏虽然已固定松手后的宽度，但仍有 220 像素的下限。egui 折叠标题强制使用不截断排版，长分组名称和顶部工具按钮也没有为窄侧栏保留空间。

手动宽度下限改为 120 个逻辑像素，保持既有自动适应、松手位置锁定和收起后恢复宽度的行为。顶部先为新建、自动适应和收起按钮分配空间，标题使用剩余宽度；窄布局把配置数量放在标题提示中。

折叠标题在传入控件前按可用像素宽度排成单行并省略末尾，保留完整原文作为无障碍标签。深层树的缩进随剩余宽度收敛，避免缩进耗尽文字空间。配置名称、主机地址和已打开会话标题同样保留左侧文字并显示省略号，悬停可查看完整名称及地址。

回归使用实际边缘拖动事件将包含长中英文文本和六层分组的侧栏缩至 120 像素，松手后检查 120 帧宽度稳定。验证真实绘制字形保留首字、以省略号结束且不越界，并验证窄侧栏中新建按钮可点击；保留原有自动宽度、收起展开和长分组松手测试。离线预览使用生产控件和合成数据。
