# ADR-0080：面向终端重度用户的石墨灰工作台

- 日期：2026-10-15
- 状态：实施；需继续通过真实日常工作流评价成熟度

## 方向

保留已清晰的经典布局，面向长期使用 Linux 的用户，强调终端空间、紧凑信息、
准确状态和持续使用时的阅读舒适度。采用石墨灰基础表面、低饱和青绿色强调、
中性主文字和次级文字，以及统一的警告/错误色；减少大圆角和彩色图标底板。

## 实施

- `cshell-ui::theme` 集中定义工作台颜色，原生标题栏及 egui 使用深色外观。
- 菜单、工具栏、侧栏、分屏标签、底部工具区及弹窗共用表面、边界和焦点样式。
- 会话行从 46 缩为 38 逻辑像素，名称与地址分层；地址使用等宽字体，长内容
  单行省略，完整地址由原有悬停提示提供。标题显示真实配置数量。
- 常规控件保持 13px 文字，标题 16px，控件 2px 圆角；不加入无功能的按钮、
  假状态、快捷键提示或装饰面板。
- 连接配置、SFTP、终端工具的页签使用共享导航样式，选中页保留细下划线。
  各功能窗口原有高饱和提示色改为共享语义色，文字提示保持可用。
- 默认终端深色画布为 sRGB #0f141d，与离线预览一致；已有 ANSI、亮色主题和
  用户自定义终端配色仍由原有会话主题机制控制。

## 验证与产物

运行既有工作台、设置页布局、密码和会话回归；离线预览直接渲染生产 egui
控件，示例会话和终端内容有明确说明。离线预览不能证明系统输入、GPU 文本
呈现或真实 SSH/SFTP 工作流已验收，不能据此宣称完整达到 Xshell 成熟度。

继续使用默认 target；覆盖更新现有试用程序和固定日志/预览文件，不创建
新的日期目录或可执行程序副本。程序运行时待正常退出再覆盖。
