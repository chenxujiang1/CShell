# SFTP 远端主机标签与共用本地文件栏

一个原生 SFTP 窗口支持最多 32 个主机标签。打开另一份保存的服务器配置会新增标签，重复打开同一配置聚焦已有标签。右侧文件栏顶部显示主机标签、连接状态和运行任务数，提供关闭及加号选服务器入口。横向滚动显示较多标签。

每个主机保留独立 IPC worker、认证连接、远端目录和导航、选择、排序、远程编辑、工作区与传输队列。切换标签移动活跃视图，不断开旧连接；后台标签继续传输和检测连接状态。断开或重新连接只作用于当前主机。关闭一个标签只断开它的连接，中断任务保留历史；关闭 SFTP 窗口会清理全部 SFTP 标签。SSH 终端不受影响。关闭最后一个标签关闭 SFTP 窗口；下次打开仍创建新会话。

左侧由一个无 SSH 会话的本地目录 reader 维护目录及分页游标，使用现有 LocalBrowse / BrowseNext / BrowseClose 协议。切换主机不重复加载本地列表，不改变游标所有者、当前页、路径输入、选择、排序和导航历史。每个主机不再自动读取一份本地目录。界面合并本地 reader 的数据与当前主机的远端数据；本地分页和导航命令显式路由到本地 reader 的 UUID，上传、下载、文件操作和队列仍绑定当前主机，禁止跨主机投递远端命令。本地目录可在远端断开时继续浏览，修改文件和传输需连接主机。跟随本地目录链接在异步 worker 中解析，再使用现有防链接替换的本地读取接口。

共用布局与本地界面状态在标签面板间移动；远端文件列表、路径输入与队列的 egui 状态按会话 UUID 分隔，标签滚动条自身使用稳定 ID。关闭 worker 的有界网络清理在后台线程执行，避免关闭标签阻塞界面。独立本地 reader 退出时释放其目录句柄。未活跃标签仅读取轻量状态用于徽标，不克隆文件列表。

验证覆盖实际控件的右侧位置、选择、关闭、加号选主机和断开后继续显示标签；本地 UI 与远端选择/页面隔离；认证 IPC 的双主机同时连接、旧主机保持轮询、远端目录保留、共用本地分页不重载、重复打开聚焦和单独关闭；真实后台在没有 SSH 会话时读取及分页本地目录。
