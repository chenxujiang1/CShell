# 第二轮工作流统一

范围为用户指定的操作流程、界面成熟度、键盘效率、SFTP 工作流；不安排长期体验验证。

## SFTP 文件与目录

SFTP 列表选择、内部拖放及系统拖入均接受文件、文件夹和混合内容。纯普通文件沿用现有队列；含目录的批次使用后台目录任务，上传与下载均保留目录结构和空目录，在传输区显示聚合进度、速度、剩余时间、暂停、继续、取消和失败重试。

目录任务固定源 SFTP 会话和目标目录，复用已认证连接，不依赖打开 SSH 终端。每次最多选择 128 个根项目，递归最多 10000 项 / 64 层，单文件上限沿用 64 GiB；不跟随符号链接与 Windows 目录联接，下载校验 Windows 非法名称及大小写目标冲突。后台最多两个目录任务，每批最多 96 个文件，默认文件并发 3，复用既有全局传输容量限制。

每个任务有私有持久文件队列，不删除或挤占浏览器原队列。整批先有界枚举，再建立目录；逐文件沿用原临时文件、检查点、校验和独占发布。已有同名文件不覆盖，失败后保留已完成文件。只有原队列明确允许安全重试的失败项才提供重试，结果不确定或需清理的项目不自动重放。重试排队期间不把旧失败状态当成再次失败。

取消与断线停止后续派发及在途文件；任务身份不允许复用源会话或已有持久队列的标识。后台重启不自动重建目录作业或重放操作，遗留文件日志保留；旧连接的任务不转到新连接。

IPC minor 73 添加 TreeStart/Get/Pause/Continue/Cancel/Retry，使用原 SFTP envelope。旧后台明确提示一起更新。

## 快捷操作与键盘

快捷操作搜索既有应用功能、当前窗口所有分屏的标签、保存的主机及快捷命令。动态条目使用稳定身份，连接与切换复用现有分发，快捷命令只载入草稿、不直接发送；已有草稿不覆盖。最多显示 200 条匹配项目。

应用快捷键支持 Ctrl+Shift+字母与 F2–F24，功能键可组合 Ctrl / Shift / Alt；保留系统关闭、上下文菜单、复制粘贴、标签导航、快捷操作和查找边界。提供按键录入。默认不占用额外终端功能键。

workbench-shortcuts.json 增加可选 profiles 方案。全局默认继承；当前 SSH 配置可启用独立方案，初始复制全局值，关闭独立方案后恢复继承。配置仅影响主工作台动作，SFTP 内部与文本编辑快捷键保持独立。所有方案校验冲突后原子保存，各窗口读取同一进程内配置。

## 编辑工作区

每个主机最多八个文件编辑标签，切换保留未保存正文、基础版本和独立文本控件状态。断线或重连保留旧连接草稿，可只读查看、复制或明确关闭，不自动回传到新连接。关闭脏文件先明确选择返回编辑或放弃修改；后台工作副本和记录继续沿用原生命周期。

内置编辑仍限制 256 KiB UTF-8，工作文件上限 8 MiB；新增行号、Ctrl+F 查找替换与 F3 下一处，不扩大内存限制。长文本正文独立滚动，保存 / 关闭固定在底部，展开高级区不会遮挡主操作。保存继续检查原摘要、基础版本、独占替换和原文件备份。

外部编辑器提供系统文本编辑器 / VS Code 预设、可执行程序选择和默认设置保存（sftp-editor.json）。启动使用原无 shell 参数数组协议；已有轮询检测修改，回传仍需明确保存。选择器后台运行，不阻塞 GUI。

## 流程与提示

错误按连接、认证、锁库、权限、文件冲突和结果未确认分类，保留原详情。仅按原因提供重连、解锁、查看文件或刷新，避免无差别建议重连。未确认结果先核对，不重复提交。

隧道普通保存、启动和停止收敛为明确按钮；非回环监听授权、未知状态清理及删除仍保留确认。批量会话修改保留变更预览、版本指纹与有效期，以“应用到 N 个会话”提交，移除重复勾选。

验证采用短时隔离 SSH/SFTP 回环、真实控件、协议及布局回归和固定离屏预览；不执行用户排除的长期体验验证。
