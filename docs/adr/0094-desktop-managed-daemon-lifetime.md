# ADR-0094：桌面后台随 GUI 生命周期退出

- 日期：2026-10-16

旧桌面关闭路径只退出 winit 事件循环，终端客户端的 Drop 只关闭 IPC 线程；
伴随后台由独立进程启动，reaper 只等待它退出，后台只监听 Ctrl+C。因此 GUI
关闭后后台和会话仍然存在。试用启动器预先独立启动后台也会触发同一行为。

桌面自行启动的后台和试用启动器统一设置 CSHELL_DESKTOP_MANAGED=1。该模式
才协商 DESKTOP_LIFETIME 能力，每个 GUI 进程通过一条只协商该能力的认证
IPC 连接持有租约。租约不依赖终端标签、会话切换或辅助窗口。GUI 正常退出
时 RAII 关闭连接；崩溃、强制结束也会由 OS 关闭连接，后台收到 EOF 释放租约。
认证失败的连接不计入租约。最后一个租约消失后等待 2 秒，期间重连或另一个
GUI 的租约会取消退出决定；退出决定提交后不再接受新租约，防止竞态。

租约归零触发原有 shutdown 通道，停止接受请求及退出监视器，随后关闭本地
终端进程树和 SSH 会话，最后释放发现记录与单实例锁。后台成功启动后 30 秒
仍未曾获得 GUI 租约则退出，避免 GUI 启动失败留下空后台。明确独立启动、未
启用桌面模式的 cshelld 保持原有服务语义，不因普通客户端断开而终止会话；
显式 IPC 端点也不会被桌面启动器接管。

验证包含认证失败不影响租约、最后一个租约退出、短暂断线重连、另一 GUI
保活和初始化保护。原生 Windows 验证针对隔离测试 PID 的 CShell 主窗口发送
WM_CLOSE，确认最后关闭后后台和实际本地终端子进程全部退出；另一 GUI 仍
打开时会话保留；重复打开得到全新后台且没有旧会话；强制终止 GUI 后后台
自动退出；独立服务保持运行；没有 GUI 的桌面后台在初始化超时后自动退出。
原生测试只使用 target 下可再生成的数据，未操作用户的试用后台。

本次更新清理 GUI 已退出后遗留的旧试用后台和会话。仅原位覆盖现有 bin，
不额外启动无 GUI 的后台，不删除用户配置、凭据、数据库或会话日志。
