# ADR-0076：以会话树、标签和终端为中心的经典工作台

- 日期：2026-10-14
- 状态：按用户试用反馈实施，实际使用体验待复核
- 范围：桌面工作台布局与功能入口；接续用户明确选择的经典布局

## 原因

首次试用暴露工作台不具备日常使用条件。原实现将主机/任务、同步输入、
高级功能、工作区操作和会话标签平铺为多个横栏；全局标签与分屏内标签重复，
会话面板是连接/编辑按钮列表，终端空间被持续挤占。功能入口接通不等于
完成Xshell类工作流的布局和交互验收。

## 决策

- 默认仅显示传统菜单、精简工具栏、左侧可调会话树、每个终端组的一层标签、
  中央原生终端和简短状态栏。同步输入/发送入口移到底部紧凑工具条。
- 文件/编辑/查看/会话/工具/帮助菜单分类承载高级功能；证书、Provider、
  脚本、批量编辑、继承和工作区恢复不再持续占用主工具栏。
- 会话树显示保存的文件夹/SSH/本地配置，支持搜索、单击选择、双击连接及
  右键操作；新建SSH、连接/重新连接、本地终端、SFTP和查找优先可见。
- 每个分屏组保留自己的标签行、关闭与新建；移动、复制、分屏/分离和恢复
  进入菜单/右键。布局恢复不自动启动远端会话。
- 终端保留独立GPU深色画布，应用控件采用统一的浅色中性色、字号和间距。
  提示正文/诊断详情使用悬停或主动打开窗口，避免挤占终端与无限横向扩张。
- 批量任务进入显式工作视图，但保留主菜单及返回终端入口。
- 主窗口关闭等同退出GUI，即使布局恢复暂停也可退出；子窗口在恢复期间
  继续受布局一致性约束。退出GUI不终止daemon或自动重放任务。

不修改网络、凭据、审批、同步输入授权和持久化协议；本轮不宣称完成全部
功能面板的信息架构和视觉验收。连接编辑器、SFTP细节及任务表单继续按实际
试用反馈收敛，不能将新菜单布局视为Xshell对标已达标。

## 验证

针对常用/窄窗口检查终端剩余面积、标签区域/分屏交互、会话树、菜单入口和
关键动作分发，构建当前GUI并提供独立预览运行目录。computer-use窗口观察
辅助进程初始化多次失败，错误为setup refresh/helper进程退出；不绕过工具
限制进行系统UI自动化。以程序布局测试及用户可见窗口复核补充，截图不可用
不写成视觉检查已通过；完整平台、UI任务对照和P3/P4验收仍待完成。
