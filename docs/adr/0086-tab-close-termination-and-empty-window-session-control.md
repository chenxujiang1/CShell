# ADR-0086：关闭标签终止会话与空窗口管理

- 日期：2026-10-15

用户明确要求关闭标签时一并移除对应会话。标签关闭和菜单关闭统一提交
显式进程终止，不再应用会话创建时的 KeepAlive 视图策略。只有收到关闭
回执并确认列表不再包含目标后，才移除标签；不确定的终止请求仍不重放。

最后标签清理后创建空闲元数据连接，继续读取会话列表。手动移除时若旧
连接已释放，重新建立连接并提交从工作区或界面列表捕获的确切会话 ID，
不要求先打开终端。请求的忙碌互斥、超时和后端校验继续生效；无标签的
移除完成后重新进入空闲刷新，不留在等待新终端动作的状态。

默认终端字号增至 28 px；已有字号偏好和即时调整继续使用。

兼容当前运行后台的已知主机预览响应：首次导入因已有 known_hosts 记录
被阻止时显示中文只读说明，无需重复导入。该状态仅说明存在记录，不
声明当前服务器已经验证，也不发起信任或连接动作；连接仍执行现有主机
密钥匹配、CA 和撤销校验，其他预览错误仍显示为错误。无需重启后台。

验证覆盖关闭最后一个标签、初始化握手前关闭、无标签且连接已释放时
移除残留会话、移除后继续刷新，以及 20 个真实本地 PTY 逐个关闭后从
注册表消失。密钥通知不会提交信任或连接；安全错误不转为通知。复用
默认 target、固定日志与原试用 bin，不停止用户后台或访问真实 SSH。
