# ADR-0078：工作台视觉规范与可读中文字体

- 日期：2026-10-15
- 范围：经典工作台的视觉层次、共享控件和字体

## 决策

保留分类菜单、左侧可调会话树、分屏内标签、原生 GPU 终端及底部发送区。
统一浅色控件的边框、焦点、悬停、圆角、字号和间距；工具栏使用代码绘制的
线性图标，新建按钮突出。会话使用名称与主机地址两行显示，选中行使用浅蓝
背景和左侧标记。深色标签栏将图标、名称和关闭按钮组成一个视觉单元；
右键菜单恢复共享浅色样式，避免继承深色标签的文字颜色。

原 Noto Sans SC 变量字体默认 wght=100。使用从原字体生成的 wght=400 静态
实例作为全局中文 UI 字体，生产界面、布局测试和预览使用同一文件。

## 复核

`cargo test -p cshell-ui --offline` 检查菜单、会话、标签、分屏及窗口比例。
`cargo test -p cshell-gui --offline layout -- --nocapture` 检查连接设置、SFTP、
终端工具和辅助窗口在小尺寸下的边界。构建 Windows GUI 提供独立试用目录。

`cargo run -p cshell-ui --example workbench_preview -- <output.ppm> [width] [height]`
直接运行生产工作台控件，以 egui 网格/字体纹理生成离线视觉预览，不依赖系统
窗口观察。会话和终端内容明确为示例；预览不验证 GPU 终端渲染、真实连接或
原生窗口交互。完整 Xshell 使用体验对标仍需实际工作流复核。
