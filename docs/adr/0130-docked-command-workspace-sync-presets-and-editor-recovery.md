# 命令工作区、同步方案、编辑恢复与产品标识

日期：2026-10-27。接续 ADR-0128 / 0129，完成用户确认的三项工作流和产品图标。

## 命令工作区

编辑菜单的“命令工作区”切换常驻面板，可停靠底部或右侧并拖动尺寸。独立设置只保存位置与宽高，不落盘保存历史命令和临时书签。支持不区分大小写的搜索、失败筛选、临时书签和原有命令前后定位、输出复制。

“载入命令栏”只载入完整命令，保留原有目标选择和发送检查；不直接执行，不覆盖已有草稿。历史继续来自 shell 语义集成，不推测按键，不读取 history 文件；沿用 128 条 / 128 KiB 元数据和已有输出预算。书签按会话隔离，至多暂存 32 个会话；命令淘汰后清理对应书签。

## 同步方案

目录同步窗口的“方案与规则”可命名保存目录对、方向、轻量内容比较、排除规则及保留修改时间。至多 32 个方案，绑定完整主机、账号、主机密钥及路由身份；配置中不含认证凭据。与本地默认目录、收藏、列宽和窗口布局共用原子设置更新。

加载方案按本地 / 远端顺序各请求一次目录导航，超时可重选，不重复发送。加载不会启动传输；仍需比较和选择提交。规则区分大小写，支持名称级 `*` / `?` 与路径级 `**`，至多 16 条，每条 128 字节；禁止绝对路径、父目录及不规范路径。默认无排除规则。遍历时先检查名称安全，再剪枝排除目录，不把排除项目加入任务。

保留修改时间默认关闭，仅针对文件。选择后要求来源提供 SFTP v3 能表达的秒级时间；不能表达时明确拒绝，允许关闭选项后重试。属性写入属于已有持久化队列的临时文件阶段，快速与完整校验路径均执行，成功校验属性后才发布文件。本轮不增加镜像删除、时间容差判断或后台定时同步。

## 远程编辑与恢复

“查看差异 / 冲突 / 备份”读取基础版本、当前服务器和本地草稿，可切换对照。基础版本为工作目录中的本地快照，使用摘要核对；旧文档缺少快照时诚实提示，服务器仍等于基础摘要时可补齐。内置服务器 / 备份文本对照上限为 UTF-8 256 KiB；差异计算在线程中执行并沿用行数、字节和算法预算，过期结果不授权基线变更。

保存前核对服务器摘要和属性，已知冲突在创建上传队列、改写工作副本前返回友好提示。用户核对服务器对照并勾选确认后，可接受当前服务器为新的保存基线；后台再次核对原文档版本、服务器摘要、权限、主机身份及连接代次。该操作保留草稿，不上传；最终保存仍经过已有备份替换与摘要保护。保存前检查不是服务端 CAS，外部并发修改仍由发布路径检查，继续保留已有独占替换约束。

列出此连接、此文件最近至多 8 个成功上传留下的已验证备份。读取所选备份时再次核验其摘要，不接受任意路径。恢复只将内容载入草稿，替换未保存草稿需明确勾选；用户核对后正常保存，当前远端版本仍产生独立备份。不会后台自动回滚或自动合并。保存队列结果未确认时仍按已有恢复流程处理。

IPC minor 76：新增 EditReview / EditRebase 及可选队列时间戳。旧草稿未设置新字段时保持原 JSON 编码；新 GUI 对新操作检查协议代次。

## 图标

采用石墨底、青绿色 C 形框和白色终端提示符。在字母组合、服务器插画和终端符号之间选择后者，保持 16–32 px 辨识度，与现有配色统一。项目自产几何图形，无第三方素材依赖。

提供 SVG 母版、多尺寸 PNG、Windows ICO / EXE 资源及原生窗口 RGBA；主界面以同一几何直接绘制。主窗口和独立 SFTP 窗口共享标识。桌面入口仍通过既有试用启动脚本设置数据和运行目录，不直接裸启动 GUI。ICNS 只作为打包资源提供，本轮不宣称验证 macOS 安装。

沿用默认 target、固定预览 / 日志与唯一试用 bin；不停止用户会话，不保留额外二进制副本。
