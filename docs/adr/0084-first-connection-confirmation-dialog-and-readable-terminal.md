# ADR-0084：首次连接确认弹框与终端字号

- 日期：2026-10-15
- 按用户要求，替代 ADR-0083 中跳转编辑页、手输指纹的交互。

首次连接返回 HostKeyUnknown 时自动预览当前 Profile 的服务器密钥，并显示
独立模态框：主机和端口、密钥算法、SHA256 指纹、取消、确认并连接。点击
确认直接提交屏幕所示指纹及预览 token，不再要求重复输入。收到后台保存
成功回执后自动连接，复用原失败标签；没有收到成功回执前不会连接。

手动从“主机密钥”页预览也使用同一弹框，确认后只保存。取消或 Esc 不保存，
获取与保存过程中显示进度，保存阶段阻止重复点击。弹框阻止终端输入。

后台既有 Profile revision、目标、预览有效期、token 和再次扫描校验不变。
配置变化、过期、后台拒绝和队列拒绝显示失败；已变化的服务器密钥仍拒绝
连接，不进入首次信任流程。

终端字形基础字号从 16 px 调整为 20 px。单元格大小、终端行列数、选择与
光标位置沿用同一套 atlas 度量；界面文字字号不随终端字号一起放大。

验证覆盖按钮点击提交所示密钥、取消、过期及配置变化、等待后台确认、
标签复用、窄窗口，以及实际终端字形和选区绘制。构建复用默认 target，
仅更新原试用 GUI，后台和保存的连接配置保持原有存储。
