# 0132：按需服务器资源面板

日期：2026-11-05。开发分支：`develop/1.1`。

## 用户行为

- 从主窗口“查看 → 服务器资源…”打开，跟随当前已连接的 SSH 终端。
- 打开时默认请求一次快照；自动刷新默认关闭，间隔显示 `0`。提供“刷新一次”、自动刷新开关和秒数输入。
- 开启自动刷新时默认间隔为 10 秒；可调整为 5～3600 秒，输入 `0` 即关闭。关闭后再打开面板仍回到单次采集，避免恢复未经注意的周期任务。
- 收起/关闭面板、窗口被系统遮挡或最小化时停止后续采集；恢复可见后，原先显式启用的自动刷新按间隔继续，不追补漏掉的采样。关闭面板则清除自动刷新设置。
- 切换到另一 SSH 会话时清理旧快照和待接收结果，重新以单次模式请求；未连接或本地终端不触发采集。
- 采集错误关闭自动刷新。未能确认远端采集结束时，该 SSH 传输不再接受新的采集，需重新连接后再试。

## 采集范围与成本控制

首版只支持提供标准 `/proc` 指标的 Linux 环境。显示 CPU 使用率、总内存与可用内存、Swap、1/5/15 分钟负载、运行时间；不采集进程表、目录大小、磁盘容量、网络连接或业务日志。

固定脚本通过已有认证 SSH 的独立非 PTY exec 通道执行。不申请新连接、不重新认证、不向交互 shell 输入命令，不安装 Agent，不写远端数据文件。CPU 在同一次请求中读取两次累计计数，中间 `sleep 1`；等待期间不忙循环。只返回所需字段，输出上限 4096 字节，不将原始错误输出暴露在界面或日志中。

CPU 根据前八个累计计数的差值计算，guest 不重复加算，I/O 等待不算使用率。计数回退、全零差值或溢出时显示无法计算，不伪造 0%。内存以总量减 `MemAvailable` 表示已用量；无该字段时明确报告不支持。容器或受限环境的 `/proc` 可能反映其他统计范围，界面说明此边界。

每个已认证 SSH 传输串行采集；多个复用终端共享短时缓存，缓存保留原采集时间。不同独立 SSH 传输分别采集，不能仅凭主机名或指纹认定为同一台机器。全后台最多两项采集并行，最多保留 32 个活跃传输的采集状态。成功采样后短间隔重复请求可复用结果，避免连续点击或多个窗口造成重复请求。

打开通道最多等待 3 秒，采集最多 8 秒，关闭通道最多等待 1 秒。GUI 请求可被取消；后台已经开始的那次有界采集仍完成收尾，不再创建周期任务。关闭通道或发送 TERM 不等于证明远端进程退出，只有结束回执或明确拒绝能解除不确定状态。前后核对会话及传输代次，丢弃跨重连的结果。

## 数据与协议

只有内存中的单次快照与短时共享缓存，不保存监控历史，不调用终端日志、任务输出存储或终端工具目录存储。系统自身可能记录 SSH 审计日志，这不受 CShell 控制。

复用 TerminalTools 请求类型与权限能力，增加操作 `ServerResources = 7`，协议 minor 升为 78。请求只允许操作号与会话 ID，其余参数必须为默认值，不接受任意命令。新 GUI 在请求前检查后台版本；回复是严格字段的 `Resources` 类型，并验证会话身份、数值范围和格式，不接受跨类型或跨会话结果。

本功能不改变数据库 schema、凭据布局、安全公告策略或依赖版本。正式分发前需保证 GUI 与 daemon 同步更新，并为 1.1 开发包设置相应版本；当前没有替换 1.0 试用包或推送远程。

## 验证边界

自动测试覆盖默认单次/零刷新、自动开关与最小间隔、隐藏与重新打开、失败停刷、小窗口离屏绘制、指标数值和异常输入、回复范围及未知字段、请求规范化，以及真实 SSH 协议下共享采样、终端输入隔离与缺失结束回执。

Linux 原始脚本另在本机 WSL 执行检查。该检查不等同于真实生产服务器的资源开销测量，也不等同于 Mac 实机体验验收；不承诺固定 CPU 占用百分比。
