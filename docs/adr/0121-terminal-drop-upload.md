# SSH 终端拖放上传

## 默认交互

把本地普通文件或文件夹拖入已连接的 SSH 终端，释放后直接上传，不再打开文件选择器或二次确认。拖放区域高亮；右下角非模态进度卡突出主机、目标目录、协议，集中展示文件数、字节进度、速度、估计剩余时间以及暂停、继续、取消。关闭进度卡不取消传输。默认全部成功后停留约 1.5 秒自动收起；失败、冲突及通信结果不确定保留。菜单“全局默认设置”可调整上传协议、拖放后确认、成功后收起，保存后用于后续新任务。

默认 SFTP，复用当前认证传输，不重新请求密码或动态码，沿用三路文件并发和会话覆盖/全局继承的标准或完整校验策略。文件夹始终通过 SFTP 保留层级和空目录，此规则在全局设置和协议标签中说明。SFTP 同名文件不覆盖；冲突停止该批次，已成功的文件保留，用户可通过 SFTP 浏览器检查后重传未完成部分。

ZMODEM 用于普通文件，服务器须提供 lrzsz/rz，并允许独立 exec 渠道。使用原认证连接的独立双向、无 PTY exec 渠道执行经过单引号转义的 `cd -- <目录> && exec rz -E`，不向交互终端输入任何命令。`-E` 保留现有同名文件并由 rz 改名。ZMODEM 不提供不可靠的暂停按钮，可以取消。服务器缺少 rz 时说明原因，不静默切换协议。

## 目录与任务边界

拖放接收时绑定源 SSH 会话及其连接代次。复用现有 OSC 7 / Linux 被动工作目录探测，解析一次并固定目标，随后改变目录或切换标签不会改变该任务。无法确定当前目录，或 SSH 目录在 SFTP 命名空间不可访问时，显示明确错误，不回退到家目录。独立上传子消费者不关闭源 SSH；源会话关闭、断线或换代会取消上传。SSH 保持连接时，进度窗口关闭不影响任务。

最多同时四个拖放批次；SFTP 沿用现有全局八个活动文件上限和每批三路并发。单次最多 128 个顶层路径，递归最多 10000 个目录项、64 层，不跟随符号链接/目录联接，不上传特殊设备。单个 SFTP 文件最多 64 GiB；ZMODEM 小于 4 GiB。递归扫描在线程池运行。SFTP 私有队列每批加入 96 个文件并移除已完成的上一批，避免超过队列容量；与已有 SFTP 窗口队列相互隔离。协议 minor 69 增加独立上传的启动、查询、暂停、继续、取消操作，校验源会话与任务标识，不自动重放结果不确定的启动请求。

## 验证

通过本地真实 SSH/SFTP 传输和键盘交互认证测试覆盖文件夹/空目录、跨批次、目录固定、同名冲突、ZMODEM 结束握手、终端继续使用、暂停/恢复/取消、源会话退出、跨会话操作拒绝及重复启动拒绝。测试构建将批次缩小到 3 个，使用 5 个文件覆盖跨批次；生产批次为 96。界面测试使用生产字体验证小窗口布局，并检查成功收起、错误保留和关闭进度不取消任务。隔离运行目录与固定报告位于默认 target 和现有 artifacts 目录。
