# 0098 — 明确的 SSH 断开反馈

原来确认关闭连接后仅设置一条状态描述，随后元数据客户端的常规刷新会覆盖它。标签仍与连接时相似，历史输出中的光标也可能造成可继续输入的错觉。

引入仅在 GUI 本次运行中存在的按标签 SSH 状态，区分已连接、连接中、断开中、重连中、已断开和状态待确认。多窗口共享此状态映射，标签移动后仍携带同一 tab ID 的反馈；关闭标签移除对应状态，不写入连接配置或重启恢复数据。

只有收到关闭确认并移除该标签的运行时 session ID 后，才标记为“已断开”。断开确认失败不会显示成功；重新连接完成后恢复“已连接”。元数据轮询与标签切换不会把已确认的断开状态抹掉。

视觉反馈包括：

- 标签上常驻琥珀色“已断开”标记、断开图标和对应的选中强调色。
- 终端顶部的提示条：“SSH 已断开”，说明下方为历史记录，输入不会发送到服务器，并提供就地“重新连接”按钮。
- 状态栏使用同一连接状态。历史画面保留，可选择复制；不再绘制可输入光标，也停止其闪烁调度。
- “断开中”“重连中”有独立的等待反馈，避免提前显示已断开。提示条按钮携带明确 tab ID，在分屏中也不会重连到其他标签。

验证覆盖三个窗口尺寸的生产控件、提示文字和目标按钮点击；断开确认、失败、轮询刷新、切换标签和重连后的状态转换；完整桌面回归。离线预览使用合成终端内容，不涉及用户服务器或凭据。
