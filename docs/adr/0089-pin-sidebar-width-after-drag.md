# ADR-0089：拖拽结束后固定侧栏宽度

- 日期：2026-10-16

手动模式原先仅设置布尔标记，并让 egui Panel 在 220～640 px 范围内保存
尺寸。长分组的 CollapsingHeader 会给 Frame 提供更大的内容最小宽度，
松手后面板因此被重新撑到 640 px，而不是停在用户释放的位置。

手动宽度现在是界面模型中的显式像素值。拖动使用指针相对面板左缘的位置，
释放时使用对应 PointerButton 事件坐标，避免同帧或后续移开的指针影响
最终位置。面板以 exact_size 显示自动计算值或手动值，内容不能再次撑开
它；拖拽边缘仍正常交互，收起/展开保留手动值，自动适应按钮清除手动值。

回归先确认超长中文分组会将释放宽度错误撑到 640 px，再验证修复后保持
释放处的 300 px；普通会话与长分组都连续观察 120 帧，同时覆盖释放后
同帧移开鼠标、收起/展开恢复宽度以及重新启用自动适应。

本次仅更新 GUI，不更新或重启后台。复用默认 target、固定验证日志和
原试用 bin，不建立额外二进制副本。
