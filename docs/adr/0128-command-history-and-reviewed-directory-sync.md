# 命令级导航与受审阅的目录同步

日期：2026-10-26。范围为用户确认的高频交互、命令导航和 SFTP 工作流；不安排长期体验验证。

## 终端命令

按需的 TerminalTools ShellHistory（操作 6）读取原终端解析器的内存元数据，不增加全帧或增量帧的负担。OSC 133 A/B/C/D 报告提示符、输入、执行与结束边界；OSC 7 报告当前目录。只在普通屏幕解释，分片通过原有有界 OSC 过滤器，不解析提示符、不采集终端按键、不执行输出中的指令。

每会话最多 128 条命令、合计 128 KiB 命令文本，单条 4 KiB；退出状态和耗时均来自 shell 报告，仅作交互辅助，不是执行授权或远端进程身份的证据。元数据不额外持久化，原会话日志仍遵循用户既有设置。列数变化会清理位置，后续提示符重新建立边界；重连清空旧记录并保留单调 ID，不能把旧选择映射到新命令。已超出保留范围的起始行禁用定位，仍保留命令状态。输出读取限定 64 KiB / 513 个物理行，截断或淘汰明确标注，不声称得到完整日志。

命令历史可从编辑菜单、快捷操作搜索或快捷键方案打开（新默认 Ctrl+Shift+H）；工具页支持前后选择、定位、复制命令及按需查看/复制输出。切换会话清理选择和待跳转位置，关闭工具页归还键盘焦点。

附带可选 Bash 4.4+ 与 zsh 当前 shell 初始化脚本；用户复制并在目标 shell 粘贴执行，不改写启动文件。Bash 保留原 PROMPT_COMMAND 与 PS0/PS1，不接管 DEBUG trap；zsh 使用独立 hook，返回零以保留后续 hook。已有主题如果重建提示符，需使用该主题兼容的 OSC 133 集成；不宣称适配所有提示符框架、嵌套 shell 或 tmux 配置。

## 高频键盘操作

SFTP 列表按当前可见排序执行方向键、Home/End、PageUp/PageDown，Shift 扩展范围，Space 切换所指项目，Tab / Shift+Tab 切换左右栏，Enter 打开目录或远端普通文件。文本编辑、弹层和文件操作对话框隔离这些按键。键盘移动会请求将所指行滚入可见区。路径文本编辑不再被目录导航快捷键接管；文件操作和终端工具关闭后交还焦点。

## 目录比较与同步

IPC minor 74 新增 SFTP SyncScan 61 / SyncApply 62。入口整合在原主机工具栏与更多功能菜单；不新增常驻工具行。比较左右当前目录的内容，预览绑定会话、连接实例、连接代次、方向、两侧根目录及随机任务 ID，五分钟有效。每侧最多 10000 项、64 层，合并最多 10000 项，回复最多 4 MiB；拒绝链接、联接、特殊文件、无效本地名称和可识别的重复目标。读取并发最多两个，比较阶段不修改文件。

名称、类型、大小、秒级修改时间用于快速比较。“元数据一致”不表示内容哈希一致；缺失修改时间的文件保守视为变更。现有传输不会承诺保留源时间戳，因此后续比较可能仍显示同内容的时间差，不自动覆盖这类项目。传输本身继续采用用户选择的校验策略。

明确选择单向上传或下载，逐项或批量选择差异。同名变更默认跳过，可显式选择原有“独立备份后替换”策略；文件/目录类型冲突不能直接覆盖。保留目标端额外文件，不做镜像删除，不同步所有者/ACL。选择文件时补齐所需父目录，保留空目录。

提交前重新枚举两侧并比对预览；目录或连接变化、预览过期、重复提交均拒绝。预览一次性认领后不自动重放。文件传输复用原有有界队列、独占发布、备份、校验和目录任务进度，支持已有暂停/继续/取消/已确认失败重试。任务绑定原连接代次，断线后不迁移到新连接。回执丢失时查询原任务 ID，不再次提交传输。暂停与取消不承诺回滚已经完成的文件。

应用层检查不代表对外部写入者的文件系统隔离；传输阶段继续沿用原源文件、目标版本和发布检查。后台重启不重建或重放未确认的同步任务。
