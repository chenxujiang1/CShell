# ADR-0077：统一弹窗、连接设置页和二级菜单布局

- 日期：2026-10-15
- 状态：已实施；实际窗口视觉与完整工作流仍待复核
- 原因：用户反馈添加 SSH 仍布局混乱，要求检查全部标签页和按钮二级菜单。

## 决策

1. `cshell-ui::form` 提供视口内窗口边界、纵向滚动、独立字段行和受限菜单宽度。
   下拉框的当前值保持单行；展开后允许长名称换行并纵向滚动。
2. 连接管理分为连接配置、导入、导出；凭据管理经短菜单进入。连接配置使用有界左侧列表，
   右侧为常规、身份验证、代理/跳板、主机密钥、终端/分类。底部保存/连接独立于页面滚动。
   保存按钮突出，保存凭据仍沿用独立存储、目标与版本校验；未保存目标时明确说明步骤。
3. 左右栏的分隔线使用页面体高度，禁止占用为底部按钮预留的空间。
   连接请求入队后收起编辑器并清除临时秘密；连接错误重新显示编辑窗口。
4. SFTP 拆为文件浏览、传输队列、远程编辑、历史/迁移。队列版本变化在所有页重置确认状态，
   保留原有单条传输、发布、恢复、迁移与编辑确认条件。
5. 任务、主机组、终端工具、同步输入、凭据、隧道、CA、Provider、继承、恢复和剪贴板窗口
   共用边界；按钮组允许换行。虚拟列表的文字保持单行，避免文字换行破坏固定行高。
   普通表单与说明允许换行；终端标签和 Hex 等有意横向浏览区域保持其专用布局。
6. 工作台顶层菜单、工具二级菜单、分屏菜单和标签/会话右键菜单共用有限宽度与纵向滚动。

## 检查范围

| 入口 | 实施内容 | 定向检查 |
|---|---|---|
| SSH / 本地连接、文件夹、导入导出 | 分类页、字段行、有界列表、固定操作区 | 中文字体、长名称/路径、各 SSH 设置页、四类认证/路由、保存/连接点击 |
| SFTP 四页 | 分类、窗口/字段边界、队列确认失效 | 长路径/文件名，四页边界 |
| 终端工具六页 | 换行导航、规则编辑、窗口滚动 | 填充高亮/触发器草稿，六页边界 |
| Vault / 凭据包、隧道、CA、Provider、批量编辑、继承、恢复 | 窗口、字段、按钮/下拉框 | 离线默认状态窗口边界 |
| 命令/上传/下载/混合任务及结果、分析、搜索、合并、归档、工作区 | 控件换行、列表行高、任务侧栏范围 | 共享任务定义窄栏；其他执行状态尚待真实任务复核 |
| 同步输入、Compose、脚本状态、查找、剪贴板策略/确认 | 共享窗口、字段、按钮布局 | 源码巡检、编译；系统输入/授权状态待原生复核 |
| 工作台菜单、二级菜单、分屏和右键菜单 | 菜单宽度/滚动、展开与命令分发 | 900×600、720×480 下展开和点击；既有右键/分屏回归 |

自动布局检查使用生产 Noto Sans SC 字体，覆盖 1280×800、900×600 以及 720×480 逻辑尺寸。
它们不证明真实 SSH/SFTP、系统剪贴板、所有长任务状态、完整 DPI/平台矩阵或 Xshell 易用性对标通过。
computer-use 的原生窗口观察辅助进程因 Windows sandbox 初始化失败，未获得截图或实际鼠标视觉验收。
本次不修改数据库、协议、后台执行与凭据权限边界，不关闭 P3-099/P4 验收。
