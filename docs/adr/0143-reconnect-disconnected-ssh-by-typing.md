# 0143：断线终端输入触发重连

日期：2026-11-13

## 行为

当前窗口的 SSH 标签已经确认断开时，终端正文中输入文字、空格、按 Enter，或开始输入法按键/提交文字，可以显式触发原标签的重新连接。使用原来的 SSH 重连控制路径：核对标签及保存的配置，确认关闭旧运行时，再创建新的 Shell；认证、跳板选择、凭据库及主机指纹确认继续沿用现有流程。

触发重连的文字不发送、不保存待重放。连接过渡期间继续输入也丢弃；跟踪这些物理按键，吞掉按住重复及松开事件，避免快速连上后发送回车、重复字符或 Kitty key-up。窗口失焦期间丢失的松开事件可由下一次真正的新按键恢复。输入法的旧预编辑和延迟提交在重连边界隔离，新一轮输入法组合可正常提交。

复制、全选、粘贴快捷键、翻页、方向键、Esc、修饰键不触发重连。编辑框、搜索、帮助、认证及其他阻塞对话框、命令编辑区域、后台窗口、本地终端、空标签、只读或暂停的工作区不触发。连接状态未确认时继续保留显式重连入口，不将普通输入当成关闭旧连接的授权。

正在连接或断开时不重复创建连接，不积累终端输入；后台自动重连设置的含义不变。断线横幅、状态栏与快捷键帮助同步说明新入口及本次输入不会发送。

## 验证

输入分类覆盖可打印 ASCII、中文、Enter、输入法 Process，以及复制组合键、导航和控制字符。验证失焦、本地及未确认标签、只读/暂停、编辑框和对话框不会触发。重连 IPC 夹具分别以按钮、Enter、普通文字和中文提交触发，确认沿用原标签及配置，重复输入只创建一个新连接，激活按键及 key-up 不发送；随后新输入可以到达新会话。原有旧会话关闭未确认时不得创建新连接的回归继续保留。

输入法测试确认重连丢弃旧组合及迟到提交，新预编辑/提交可用。相关键盘、IME、焦点、同步输入、帮助与布局回归在本地验证；复用默认 target 和固定报告，仅更新现有 Windows 试用目录。Mac 实机行为及完整远程 CI 仍需单独验收。未提交或推送。
