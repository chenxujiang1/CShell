# ADR-0090：SFTP 双栏文件列表与底部传输任务区

- 日期：2026-10-16

SFTP 默认页改为左侧本地、右侧远端的文件管理器。两侧分别提供路径栏、
上级目录、刷新、名称和大小列表；目录优先排序，双击目录进入，文件名
左对齐并截断长名称。文件可从列表拖到另一侧，系统文件也可拖入远端区。
拖入区域高亮，目标使用已加载目录，路径栏尚未提交的文字不会改变目标。

底部固定任务区列出待提交文件及后台任务，显示方向、状态、进度、大小、
速率和预计剩余时间。点击“开始传输”一次提交选择并启动全部等待项；
也可只加入等待队列。冲突策略、编辑、历史和迁移保留在其他页，默认拒绝
已有目标；本次支持普通文件，文件夹不递归传输。

暂停先通过现有 QueuePause 阻止派发后续文件，再对所选任务的确切
transfer_id 发送 CancelTransfer，保留校验传输的暂存内容。界面区别显示
正在暂停和已暂停，通过 QueueResumeVerified 校验后续传。发布和清理阶段
禁止暂停。取消使用同样的目标核对并清楚显示等待状态；等待项可直接取消。
后台处理期间禁用重复操作，所有修改保持会话和队列版本核对，不自动重试
结果不确定的写入。仅加载目录或绘制界面不会自动启动已有任务。

回归包括真实指针双向拖放、底部按钮在 720×480 等窗口中的位置、暂停/
取消/继续命令、重复点击、跨会话及路径越界拒绝、批量添加回执核对，以及
暂停先于取消的模拟 IPC 往返。离线生产控件预览输出固定 sftp.png，文件
与进度均为示例，不连接服务器。完整 GUI 回归及原生窗口自检按固定日志
覆盖保存；仅更新现有试用 GUI，后台和正在运行的会话不重启。
