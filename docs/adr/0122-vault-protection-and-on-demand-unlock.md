# 凭据库保护方式与连接时按需解锁

## 交互

新建凭据库默认使用系统托管；已有库保持现有保护方式，不自动转换。全局默认设置新增“凭据库与安全”，显示后台确认的当前模式、锁定状态和恢复入口，可在系统托管与自定义主密码之间无损切换。保护方式独立应用，文件传输设置使用单独的保存按钮，避免尚未迁移却显示“已保存”。主状态栏显示凭据状态，可直达全局设置。

发起 SSH、复制独立 SSH 会话、手动重连或独立 SFTP 时，先准备凭据。系统托管库在没有手动锁定时自动解锁；自定义主密码库通过连接中的本地弹框解锁，成功后继续同一次连接，不重新发起 SSH 或重放动态验证码。错误主密码允许有界重试，取消返回已有 AuthenticationCancelled 流程，尚未建立的新标签关闭，不自动打开配置编辑器。已有 SSH 上复制渠道、打开共享 SFTP、终端拖放上传继续复用认证连接，不要求读取凭据库。

解锁弹框有后台生成的 vault_unlock 类型标记，与不可信服务器提示区分。主密码只交给本地凭据库，SSH 尚未打开 TCP 连接；动态码验证在本地解锁之后进行。身份验证答案、请求和密码缓冲沿用原有清零与日志脱敏。后台状态轮询不会解锁库。解锁准备（包括排队与重试）总计最多等待 120 秒。并行连接通过准备门串行化，复用一次解锁；已取消的 SFTP 请求不会因等待结束而继续连接。

解锁后在本次程序运行期间持续有效：锁屏、休眠、系统会话断开、切换应用、监控不可用以及凭据闲置均不自动锁库，也不取消在途认证。移除 15 分钟闲置期限和后台定时锁库任务。系统会话观测只保留诊断信息，不限制凭据操作。用户手动锁定与程序退出清理使用不同操作：手动锁定后需要明确确认再解锁，退出时清除内存解锁状态；再次打开主密码库需要按需解锁，系统托管仍可在发起连接时自动解锁。已有连接保持运行。

## 无损迁移与恢复

迁移验证当前库版本、锁定代次、库的独占所有权及已解锁状态。主密码转系统托管需要重新验证当前主密码；系统托管转主密码先确认系统密钥有效，再使用用户设置并确认的新密码。全局操作拒绝夹带会话配置、重建确认等无关字段。

库内全部六类记录、原绑定和标识一并复制到受保护的新代次，使用原 AES-256-GCM / Argon2id 格式重新加密。读取磁盘重新加载并验证新库后，复用现有原子活动代次指针发布机制；无需将明文凭据导出到 GUI 或临时文件。迁移与重建互斥，普通凭据写入通过版本/代次栅栏阻止过期快照被提交。

发布前失败保留原活动库；只清理此次确实创建、且确认未发布的候选系统密钥，创建被拒绝时不能删除已有密钥。结果不确定时保留密钥并锁定，要求显式重新加载活动指针，不自动重放。原加密库文件保留，不删除已有凭据数据。

系统托管转主密码提交成功后，清理该次源库的系统密钥，避免保留可直接解密源副本的系统入口。失败的候选系统密钥或已退休密钥清理失败时保留标记，全局设置显示实际已生效模式，要求解锁并完成清理后再切换。清理前验证当前活动路径，不能删除当前库仍在使用的系统密钥。

保护方式只改变当前活动库，不迁移/删除会话单独使用的系统密码、外部私钥、已有导出备份或更早重建保留的历史库。需要迁移这些凭据时使用已有导入/加密备份流程。丢失原解锁能力不能通过切换保护方式绕过解密，只能恢复备份或明确保留旧库重建。

## 协议与验证

IPC minor 70 增加 ProtectWithSystem / ProtectWithPassword / FinishProtectionCleanup / LockTransient 操作，以及手动锁定、待清理和本地解锁标记。旧后台不支持迁移时明确提示一起更新；内部锁定对旧后台回退到原 Lock 操作。

验证覆盖所有记录类型和绑定、错误密码/过期请求不改库、已存在系统条目不误删、发布失败及提交后不确定、重启后读取、长时间闲置和锁屏/休眠/监控失效不锁库、手动/退出锁定区别、本地解锁取消及重试、真实回环 SSH/SFTP 中主密码与动态码顺序、Windows 原生凭据管理器自动解锁与密钥清理，以及小窗口生产字体布局和敏感字段清理。测试仅使用隔离目录和自建系统凭据条目，不迁移用户实际凭据库。

系统托管的安全边界是系统登录身份，不等同于每次 Windows Hello 验证：[Microsoft CredReadW](https://learn.microsoft.com/windows/win32/api/wincred/nf-wincred-credreadw)。

2026-10-23 按用户指定的使用体验更新解锁生命周期。旧 ADR-0012/0026/0027 中的自动锁库策略由本文覆盖；手动锁定的代次栅栏、退出清理和文件错误恢复机制保留。
