# SFTP 列表多选与当前页文件操作

本地与远端列表分别按完整路径保存选择集和范围锚点。Ctrl 单击切换选择，Shift 按当前显示排序选取连续范围，Ctrl+Shift 添加范围，Ctrl+A 选择当前页。刷新相同目录保留仍存在的项，成功切换目录、分页替换或切换会话时移除过期选择；加载中的空列表不会提前丢弃选择。导航项 `.`、`..` 不参与选择。

文件行直接处理点击及拖动，避免外层拖放容器抢占普通点击。右键选中项保留已有选择，右键未选中项改选该项。右键菜单及“操作”菜单提供打开目录、上传/下载所选文件、重命名、新建目录、属性/权限、复制路径及刷新。普通文件最多 128 项批量传输，混合目录或超量拖放明确提示，不静默忽略目录。

F2 在当前栏打开单项重命名，Ctrl+Shift+N 新建目录。文字编辑、菜单及操作弹框拥有输入时不抢占文件快捷键。名称仅作为当前已载入目录的直接子项，拒绝路径分隔符、控制字符和 `.`/`..`；后台仍校验完整路径及拒绝覆盖已有目标。

当前页模态弹框展示选定路径、名称或属性、POSIX 权限。读/写/执行及特殊位复选框与八进制权限同步；多项权限不同时明确说明将统一设置，不递归修改子项。未知权限不猜测默认值，需用户填写。Windows 本地权限由 ACL 管理，当前弹框仅查看属性；符号链接和特殊文件不提供 chmod。多选展示已知文件大小合计，不将首个文件大小误作总量。

一次“应用”授权弹框中的具体修改，前端按原有 FileInspect → Ready → FileApply 协议自动推进。每项绑定新任务 ID、会话、完整草稿、权限代次和提交版本；每次应用只发送一次，后台保留命名空间锁、源/目标变化复检和无覆盖操作。批量权限逐项执行，失败、回执异常、状态代次变化或请求拒绝时停止后续项，显示已完成数量并保留错误，不自动重放。完成后关闭弹框并刷新原目录，等待回执期间保留状态弹框。

验证覆盖真实鼠标 Ctrl/Shift 选择、右键保留选择、排序范围、刷新/会话隔离、F2 文字替换、Ctrl+Shift+N 与 Enter、批量传输、防重复应用、失败停止、Windows 只读权限与 720×480 弹框。显式设置 CSHELL_SFTP_TEST_FILE_OPERATIONS 和项目内 CSHELL_RUNTIME_DIR 的 SSH/SFTP 用例验证本地和远端目录创建、目录/文件重命名以及远端目录/文件权限的实际变化，不触及用户运行目录。
