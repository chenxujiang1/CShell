# 0123：高效的多目标命令栏

状态：已实现，验证通过并原位更新试用 GUI。

当前同步输入要求目标预览、启用确认，以及每条 Compose 正文预览；即使普通命令追加 Enter 也被分类成控制字符，导致正常命令每次都要求风险确认。

采用默认命令栏模式，保留自定义目标和可选实时键盘同步。目标列表显示后点击启用即作为普通规模目标的明确授权；超过 10 个目标继续使用独立的冻结目标确认，且不在打开确认框的同一帧接收原启用点击。

普通单行命令 Enter 发送，多行 Enter 换行、Ctrl+Enter 发送。发送后命令栏保持打开并清空正文；可选预览按钮继续可用。快捷命令的显式执行与命令栏共用分类和派发。

应用层将显式 append_enter 选项与正文内嵌控制字符区分。正文换行、回车、控制字符及已有危险命令识别仍要求 Confirmed 审批；GUI 继续保留风险勾选与明确发送按钮，不能仅按 Enter 绕过。所有派发仍受冻结身份、期限、安全上下文、审计及队列许可校验。风险识别是辅助提示，不是完备的 shell 命令安全判定。

命令栏目标不是实时键盘广播。普通终端按键、粘贴和 IME 只在明确实时模式下走广播；命令栏的 IME 预编辑及确认 Enter 不发送命令。当前活动标签不必包含在命令目标中。切换“仅当前终端”不改写已选择的命令目标。

参考：

- [Xshell 官方：多会话输入](https://netsarang.atlassian.net/wiki/spaces/ENSUP/pages/1118601758)：撰写栏/撰写窗格选择发送范围，编辑后发送；实时按键同步是独立入口。
- [SecureCRT 官方：Command Window](https://www.vandyke.com/support/scripting/scripting-examples/command-window-automation.html)：命令窗口支持多个目标范围，并区分完成编辑后发送与即时字符模式。

本实现保留当前窗口和标签组的 SSH 批选及自定义选择，不对新开标签自动扩充目标；不将命令内容写入审计或增加磁盘命令历史。

补充保护：选择目标及大组确认打开时禁用后台命令栏发送；Esc 返回编辑。Enter 与按钮共用 UTF-8 字节限制。零宽字符、双向文本控制及 Unicode 行分隔符与内嵌控制字符一同进入风险确认。

## 第二轮：紧凑命令栏与连续操作

根据实际使用反馈，普通发送默认使用 42 个逻辑像素高的单行命令栏；多行编辑才展开。范围、正文、历史、发送和更多位于同一行。预览、追加 Enter、快捷命令管理移入更多菜单。下拉箭头直接绘制，不依赖符号字体。

范围按钮就地展开当前会话、当前标签组 SSH、当前窗口 SSH 和自定义列表。自定义可搜索、全选 SSH、清空和逐项勾选；点击应用即冻结目标并返回编辑，普通规模不再另点启用。超过 10 个目标仍保留第二次确认，且不在打开确认框的同一帧接收应用点击。批选仅使用当前窗口内已就绪 SSH，本地终端仍手选，不混合协议。

命令接收标签显示单行“命令”标记，实时同步显示“同步”；当前查看标签沿用原有选中样式。改为仅当前发送时，标记随实际范围切换，同时保留先前冻结范围供显式恢复。新连接不会自动加入。

命令历史仅记录已获得至少一个队列接受回执的命令栏提交，不采集普通终端输入，不写入设置、审计或磁盘历史。最多 100 条且累计 UTF-8 正文不超过 256 KiB，重复命令移至最近，淘汰和清空时销毁 Zeroizing 正文。单行 ↑/↓ 回调并恢复未发送草稿，历史面板可搜索、填入编辑、清空。历史回调本身不发送，风险正文重发仍走相同确认路径。历史可能包含用户写入命令栏的敏感内容，界面明确提示并提供清空入口。

普通命令栏切换标签和短暂失去窗口焦点时保留草稿与冻结目标，同时撤销尚未写入的旧队列、废弃待确认正文并重置确认状态。实时键盘同步保持失焦停止。关闭、重连、安全上下文和审计检查继续有效。弹出面板期间背景编辑器禁用，IME 确认和面板中的 Enter 不穿透发送；关闭面板后恢复编辑焦点，历史光标落在正文末尾。

发送反馈缩短为“已入队 N/M”，详细失败保留主机名称与原因；悬停明确入队不表示远端执行成功。快捷命令列表默认填入命令栏并沿用当前范围，核对后发送；编辑管理及任务模板保留独立入口。本轮以轻量命令栏、范围选择、接收目标标记和历史复用为交付重点。

## 第三轮：稳定范围、常驻输入与后台活动

实际使用暴露了隐藏标签连接回收问题：控制通道原先只有可见或已选择目标才会保留，尚未选中的新会话可能因此一直不可选；切换时重建控制通道的短暂未就绪还会触发整个目标范围失效。现在每个本窗口打开的运行会话复用一个 IPC 附着，隐藏标签也保留控制能力；只附着已有会话，不建立新的 SSH 连接，不恢复旧会话。隐藏客户端只保留最新的有界终端快照，界面只更新可见分屏的渲染表面，红点已存在时不因每批后台输出重复要求终端重绘。

新连接就绪后立即可手动选择，范围菜单增加“加入当前会话”。新连接仍不自动加入冻结范围，以避免意外扩大命令接收主机。

命令栏随打开的会话默认显示，保持 42 个逻辑像素高；移除其下重复的同步输入工具行，查找、命令库、管理和显式实时同步放入更多菜单。显示本身不抢占终端输入焦点；点击编辑器输入命令，点击终端恢复普通终端输入，命令栏保持可见。只有手动关闭或在编辑器内按 Esc 才隐藏；终端中的 Esc 不会收起命令栏。默认显示只属于本次运行的 UI，不保存会话或目标到磁盘。

普通弹窗暂时阻止命令提交、废弃旧确认与未写入队列，不清空编辑器或命令范围；实时同步仍会停止。正常发送、切换标签和窗口不收起命令栏。真正的断线、身份变化或审计失效会停止发送并保留“目标已暂停”，禁止退回当前会话悄悄继续发送；用户需要明确选回当前会话或重新应用目标。

后台活动提示复用现有终端帧代数，不增加后台协议字段。每个打开标签只存会话 ID、代数、行列数和一个未读位；首次快照建立基线，尺寸变化不触发红点，同会话且相同行列的后续代数更新标记新输出，查看对应标签或可见分屏后清除。更换会话、代数重置、关闭标签和重启会清理状态。红点静态绘制在标签图标和标签列表入口，列表中也标识对应项目，支持大量标签或标签滚出可见区的情形；无闪烁、声音或弹窗。

回归补上未选中新会话的真实 IPC 就绪、二十个本地 PTY 下隐藏标签附着身份不变、后台真实输出产生红点及切回清除，以及发送后弹窗、终端焦点、手动收起、暂停范围不回退和高 DPI 标记边界。

## 第四轮：清晰且有界的多行发送预览

确认页改为当前原生窗口内居中的模态层，有遮罩阻止后台输入；不恢复旧窗口的边角位置，不允许拖动后遗留在屏幕外。宽度按当前可用逻辑宽度约 78% 计算，常规下限 600、上限 920，始终受窗口两侧留白约束。高度按可见目标行数与正文行数自适应，上限为当前窗口高度的 85% 且不超过 720；实际外框另含边线。逻辑像素随系统 DPI 缩放。

标题明确说明向多少主机发送什么，标注“尚未发送”。接收目标与命令分别展示；目标名沿用冻结快照，配置账号 / 地址在创建预览时取同一运行会话并冻结，显示“配置”前缀，不当作本次验证的真实端点。多目标列表独立滚动，长名字与地址省略后可悬停查看。

命令以 15 点等宽字体和行号展示，保留自然的 LF / CRLF 换行、缩进及空行，行号和显示标记不进入发送正文。行数不等同于命令数，不承诺逐台执行或失败停止。命令区独立支持横向及纵向滚动，不强制折行，长文本采用可见行绘制；普通换行不再显示 LF 标记。异常控制字符、制表符与不可见字符用方括号标记，原始冻结正文不被改写。

底部操作区固定，长正文和目标列表不能挤走“返回编辑”“发送到 N 台主机”和详细信息。普通多行由明确发送按钮完成一次确认，不重复勾选；危险命令和非普通换行的控制字符仍额外勾选。应用层 multiline / controls / destructive 的 Confirmed 审批校验完全保留，额外大组目标确认不变。字节数、粘贴语义和有效期放入详细信息。

返回、Esc 和关闭均废弃待确认对象但保留原稿、范围与编辑状态，恢复编辑焦点；点击遮罩不关闭或发送，初始焦点放在返回编辑而非主按钮，避免编辑框提交键穿透。预览沿用应用层 30 秒期限，过期后禁用发送并提示返回重新确认，不自动延长或重新签发。若提交时连接身份变化或没有成功入队，保留草稿，不清空用户内容；入队仍不等于远端执行成功。

验证覆盖 720×480、900×600、1280×800 与 100% / 125% / 150% / 200% 缩放下的居中、边界和固定操作按钮，以及 64 个长主机名、四千多行正文、长行、风险勾选、返回 / Esc / 关闭、期限和连接身份变化。预览产物固定为 ssh-send-review.png 与 ssh-send-review-small.png，使用生产控件的离线示例。
