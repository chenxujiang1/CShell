# CShell 1.0.0

CShell 1.0.0 是 1.0 系列的首次公开试用版本，面向 Windows x64、Mac Apple Silicon（M 系列）和 Mac Intel 用户收集使用反馈。

## 主要功能

- SSH、SFTP 和本地终端，多标签与分屏工作区，连接配置和凭据管理。
- 支持系统钥匙串、凭据库及 SSH Agent 等认证方式；按连接实际凭据来源请求解锁。
- 服务器重装或主机密钥变化时展示新旧指纹，核实后可确认更新并重新连接。
- 优化中文显示、粘贴回显、双击分词、选区取消、复制粘贴及窗口切回后的输入焦点。
- 改善 `tail -f` 等连续输出场景的滚动、查找和复制体验；暂停视图跟随时后台继续接收，可通过“返回最新”恢复跟随。
- 统一桌面与后台的数据路径，覆盖旧试用目录识别、数据库升级备份和失败回滚，降低升级后配置列表为空的风险。

## 下载与首次运行

| 设备 | 下载附件 |
| --- | --- |
| Windows x64 | `CShell-trial-windows-x64.zip` |
| Mac M 系列 | `CShell-trial-macos-arm64.zip` |
| Mac Intel | `CShell-trial-macos-x64.zip` |

每个 ZIP 附同名 `.sha256` 文件，下载后先校验。GitHub 自动生成的 `Source code` 文件是源码，不是可执行程序。

Windows 解压后保持 `CShell.exe`、`cshelld.exe` 和 `cshell-script-worker.exe` 在同一目录，双击 `CShell.exe`。Mac 解压后将 `CShell.app` 拖入“应用程序”，从 Finder 打开。无需安装 Rust。

## 从旧试用版升级

正常退出桌面与相关后台，再替换整套程序文件或整个 app，保留原有用户数据。普通 Windows 数据位于 `%LOCALAPPDATA%\CShell`；Mac 位于 `~/Library/Application Support/CShell`。若设置了自定义数据路径，继续使用原路径。早期带 `Start-Trial.cmd` 的 Windows 试用目录还须保留原启动器、`data` 与 `runtime`，不要只复制 EXE。

此前下载的 `0.1.0` 试用包需要替换为本次 `1.0.0` 包；改文件名不会更新程序版本。系统钥匙串授权属于操作系统账户，新构建替换旧程序后可能需要重新授权。请不要删除旧配置、凭据库或备份来尝试解决连接问题。

## 已知限制

- 本版仍是公开试用，建议先使用测试服务器和非关键文件，并备份重要配置。
- Mac 包使用 ad-hoc 签名，尚未提供 Developer ID 签名与 Apple 公证。若系统拦截，核对来源与 SHA-256 后按 [Apple 官方说明](https://support.apple.com/102445)处理，请勿全局关闭 Gatekeeper。
- Mac 构建与自动检查使用 macOS 15；更早系统、真实硬件性能、浏览器下载后的首次启动仍需实机反馈。虚拟 GPU CI 通过不代表物理 Mac 性能已验收。
- 当前通过手动替换程序升级，未提供自动更新；终端历史有保留上限，重要输出请另存。
