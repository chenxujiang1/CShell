# CShell 1.1.0

软件版本：`1.1.0`。构建编号：`11002`。

## 新增与改进

- **跳板连接：**使用 CShell 建立受管理的 A → B 会话，可使用 A 上的密钥认证 B，并按需复用已认证的跳板。标签、上传和资源面板标明实际路线。在 A 的终端中手动运行 `ssh B`，CShell 的文件操作和采集目标仍是 A。
- **服务器资源：**从工具栏打开 Linux 基础资源面板。默认采集一次，间隔为 `0`，无需安装常驻服务，也不保存监控历史。最小化恢复后可看到已发出的采集结果；重连后丢弃旧连接的快照。
- **拖拽上传：**SFTP 支持暂停、取消、移除和重试失败项，保留原清单与已成功文件。同名文件不覆盖。明确被拒绝的请求可以直接移除；结果不明时仍可查询原任务。上传成功后可从任务面板在 SFTP 打开原目录，原 SSH 连接变化或目录不可访问时会提示。
- **终端与连接：**改进 Ctrl+C、中文输入、鼠标选取、复制粘贴及持续输出回看。断线后可按键进入恢复流程，之前的命令不会自动重放。连接诊断按需展开，快捷键说明可在“帮助”中查看。

## 下载与升级

Windows 请选择 x64 包。Mac M 系列请选择 arm64 包，Intel Mac 请选择 macOS x64 包。下载后核对同名 `.sha256`；包内 `build-info.json` 的版本、构建号和来源应与本 Release 一致。下载附件中的程序 ZIP，无需安装 Rust。

升级前正常退出 CShell 及其后台，替换整套程序或 `CShell.app`，保留原有数据目录。Windows 旧便携布局需要保留原 `data`、`runtime` 和启动器。详见[升级与配置保留](https://github.com/chenxujiang1/CShell/blob/v1.1.0/TRIAL.md#升级与配置保留)。

## 已知限制

- 当前 Mac 构建只有 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。系统可能阻止首次打开；请核对下载来源和校验值，按 [Apple 支持说明](https://support.apple.com/102445)处理。托管 CI 不代表所有 Mac 系统、显卡和实际升级场景均已验收。
- 上传失败项重试仅适用于原 SSH 连接仍可用，且已有足够依据安全恢复的 SFTP 任务。清单过期、原连接失效、发布结果不确定或 ZMODEM 任务需要先核对远端文件。
- 资源面板只展示常见 Linux 的基础指标。自动更新、独立远程日志工作台、远程全文搜索和 Docker 管理不在本版范围。
